## ১. টাইম-সিরিজের মৌলিক উপাদান ও ক্লাসিক্যাল ডিকম্পোজিশন

একটি টাইম-সিরিজ $Y_t$ চারটি উপাদানের সমন্বয়ে গঠিত:
1. **Trend ($T_t$):** দীর্ঘমেয়াদী ঊর্ধ্বমুখী বা নিম্নমুখী সাধারণ গতিপ্রকৃতি।
2. **Seasonality ($S_t$):** নির্দিষ্ট ক্যালেন্ডার সময় পরপর হুবহু পুনরাবৃত্তি হওয়া ওঠানামা (যেমন: প্রতি ডিসেম্বরে বিক্রয় বৃদ্ধি)।
3. **Cyclic ($C_t$):** নির্দিষ্ট সময়কালহীন অর্থনৈতিক বা ব্যবসায়িক চক্র (যেমন: ৪-৫ বছরের মন্দা)।
4. **Residual / Noise ($R_t$):** অপ্রত্যাশিত দৈবচয়নমূলক অনিয়মিত ঝাঁকুনি।

### এডিটিভ বনাম মাল্টিপ্লিকেটিভ ডিকম্পোজিশন:

```
        Additive Model (Y_t = T_t + S_t + R_t)            Multiplicative Model (Y_t = T_t * S_t * R_t)
   Y                                                 Y
   ^             /\             /\                   ^                            /\
   |            /  \           /  \                  |                           /  \
   |      /\   /    \    /\   /    \                 |              /\          /    \
   |     /  \ /      \  /  \ /      \                |             /  \        /      \
   |    /    v        \/    v        \               |      /\    /    \      /        \
   +-----------------------------------> Time        +-----------------------------------> Time
     সিজনালিটির বিস্তার সর্বত্র সমান থাকে                ট্রেন্ড বাড়ার সাথে সাথে সিজনালিটির বিস্তার বৃদ্ধি পায়
```

### ১.৩ সেন্টার্ড মুভিং এভারেজ (CMA) দিয়ে ডিকম্পোজিশনের হাতে-কলমে ১২ মাসের হিসাব

ধরি একটি স্টোরের ১২ মাসের বিক্রয় ডেটা ($Y_t$):

| মাস ($t$) | ১ (Jan) | ২ (Feb) | ৩ (Mar) | ৪ (Apr) | ৫ (May) | ৬ (Jun) | ৭ (Jul) | ৮ (Aug) | ৯ (Sep) | ১০ (Oct) | ১১ (Nov) | ১২ (Dec) |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **বিক্রয় ($Y_t$)** | ১০০ | ১১০ | ১২০ | ১৩০ | ১৫০ | ১৮০ | ২১০ | ২০৫ | ১৮০ | ১৫০ | ১৩০ | ২৪০ |

মডেল: মাল্টিপ্লিকেটিভ ($Y_t = T_t \times S_t \times R_t$)
1. **ধাপ ১: ট্রেন্ড ($T_t$) নির্ণয় (১২-মাসের সেন্টার্ড মুভিং এভারেজ):**
   ১২টি মাসের মোট যোগফল $= ১০০ + ১১০ + \dots + ২৪০ = ১৯০৫$।
   গড় $= \frac{১৯০৫}{১২} = \mathbf{১৫৮.৭৫}$। সেন্টারিংয়ের মাধ্যমে প্রতিটি মাসের স্মুথড ট্রেন্ড $T_t$ পাওয়া যায়।
2. **ধাপ ২: ডি-ট্রেন্ডেড অনুপাত ($S_t \times R_t = Y_t / T_t$):**
   - ডিসেম্বর ($t=12$): $\frac{240}{158.75} \approx \mathbf{1.512}$ (গড়ের চেয়ে ৫১.২% বেশি সেলস!)
   - জানুয়ারি ($t=1$): $\frac{100}{158.75} \approx \mathbf{0.630}$ (গড়ের চেয়ে ৩৭% কম সেলস)।
3. **ধাপ ৩: সিজনাল ইনডেক্স নরমালাইজেশন:**
   প্রতিটি মাসের অনুপাতগুলোর গড় নিয়ে এমনভাবে স্কেল করা হয় যাতে ১২ মাসের সিজনাল ফ্যাক্টরের গড় হুবহু **১.০** (বা সমষ্টি ১২.০) হয়।
4. **ধাপ ৪: রেসিডুয়াল আলাদা করা:**
   $$R_t = \frac{Y_t}{T_t \times S_t}$$

## ২. স্টেশনারিটি পরীক্ষা: তাত্ত্বিক ভিত্তি, ইউনিট রুট প্রমাণ ও ADF টেস্ট

### ২.১ উইকলি স্টেশনারির ৩টি গাণিতিক শর্ত:
1. **ধ্রুবক গড়:** $\mathbb{E}[Y_t] = \mu \quad \forall t$
2. **ধ্রুবক ভ্যারিয়্যান্স:** $\text{Var}(Y_t) = \mathbb{E}[(Y_t - \mu)^2] = \sigma^2 < \infty \quad \forall t$
3. **সময়ের প্রভাবমুক্ত অটোকোভ্যারিয়্যান্স:** $\text{Cov}(Y_t, Y_{t-k}) = \gamma_k$ (কোভ্যারিয়্যান্স কেবল ল্যাগ $k$-এর দূরত্বের ওপর নির্ভর করবে, কোন সালে মাপা হয়েছে তার ওপর নয়)।

---

### ২.২ $\text{AR}(1)$ প্রসেসে ইউনিট রুট ও ভ্যারিয়্যান্স বিস্ফোরণের গাণিতিক প্রমাণ

ধরি একটি অটোরিগ্রেসিভ প্রসেস:
$$Y_t = \phi Y_{t-1} + \epsilon_t, \quad \epsilon_t \sim \text{WN}(0, \sigma^2)$$

পেছন দিকে রিকার্সিভলি প্রসারণ করি:
$$Y_t = \phi (\phi Y_{t-2} + \epsilon_{t-1}) + \epsilon_t = \phi^2 Y_{t-2} + \phi \epsilon_{t-1} + \epsilon_t$$
$$Y_t = \phi^t Y_0 + \sum_{i=0}^{t-1} \phi^i \epsilon_{t-i}$$

উভয় পাশে ভ্যারিয়্যান্স নিলে:
$$\text{Var}(Y_t) = \text{Var}\left( \sum_{i=0}^{t-1} \phi^i \epsilon_{t-i} \right) = \sum_{i=0}^{t-1} (\phi^i)^2 \sigma^2 = \sigma^2 \sum_{i=0}^{t-1} (\phi^2)^i$$

গুণোত্তর ধারার সমষ্টির সূত্র:
$$\text{Var}(Y_t) = \sigma^2 \frac{1 - (\phi^2)^t}{1 - \phi^2}$$

#### দুটি ভিন্ন পরিস্থিতি:
1. **কেস ১: $|\phi| < 1$ (স্টেশনারি):**
   যেহেতু $|\phi| < 1$, তাই $t \to \infty$ হলে $(\phi^2)^t \to 0$।
   $$\lim_{t \to \infty} \text{Var}(Y_t) = \mathbf{\frac{\sigma^2}{1 - \phi^2}} < \infty \text{ (ধ্রুবক ভ্যারিয়্যান্স, স্টেশনারি!)}$$
2. **কেস ২: $\phi = 1$ (ইউনিট রুট / রেন্ডম ওয়াক):**
   $$\text{Var}(Y_t) = \sigma^2 \sum_{i=0}^{t-1} 1 = \mathbf{t \cdot \sigma^2}$$
   - **বিপর্যয়:** সময় $t$ যত বাড়বে, ভ্যারিয়্যান্স সময়ের সমানুপাতিক হারে অসীমের দিকে ধাবিত হবে! ডেটা কখনোই তার আদি গড়ের দিকে ফিরে আসবে না। এটিই **ইউনিট রুটের গাণিতিক প্রমাণ**।

---

### ২.৩ অগমেন্টেড ডিকি-ফুলার (ADF) টেস্টের সমীকরণ
$$Y_t = \rho Y_{t-1} + \epsilon_t \implies \Delta Y_t = (\rho - 1) Y_{t-1} + \epsilon_t = \gamma Y_{t-1} + \epsilon_t$$
- $H_0$ (নাল হাইপোথিসিস): $\gamma = 0 \implies \rho = 1$ (ইউনিট রুট বিদ্যমান, ডেটা নন-স্টেশনারি)।
- $H_1$: $\gamma < 0 \implies \rho < 1$ (ডেটা স্টেশনারি)।
- $p\text{-value} < 0.05$ হলে নাল হাইপোথিসিস বাতিল।
- **ডিফারেন্সিং সমাধান:** $\Delta Y_t = Y_t - Y_{t-1}$ প্রয়োগ করলে ইউনিট রুট দূরীভূত হয়ে ডেটা স্টেশনারি হয়।

## ৩. অটোকোরিলেশন (ACF) ও আংশিক অটোকোরিলেশন (PACF)

### ৩.১ স্যাম্পল অটোকোরিলেশন সূত্র:
$$r_k = \frac{\sum_{t=k+1}^T (Y_t - \bar{Y})(Y_{t-k} - \bar{Y})}{\sum_{t=1}^T (Y_t - \bar{Y})^2}$$

#### 🔢 ৬টি ডেটা পয়েন্টে হাতে-কলমে $r_1$ ও $r_2$ গণনা:
ধরি ৬ দিনের ক্লোজিং প্রাইস: $Y = [10, 12, 16, 18, 22, 26]$ ($T = 6$)
1. **গড় ($\bar{Y}$):**
   $$\bar{Y} = \frac{10 + 12 + 16 + 18 + 22 + 26}{6} = \frac{104}{6} \approx \mathbf{17.333}$$
2. **বিচ্যুতি ($Y_t - \bar{Y}$):**
   - $t=1: 10 - 17.333 = -7.333$
   - $t=2: 12 - 17.333 = -5.333$
   - $t=3: 16 - 17.333 = -1.333$
   - $t=4: 18 - 17.333 = +0.667$
   - $t=5: 22 - 17.333 = +4.667$
   - $t=6: 26 - 17.333 = +8.667$
3. **মোট ভ্যারিয়্যান্স (হর $\sum_{t=1}^6 (Y_t - \bar{Y})^2$):**
   $$(-7.333)^2 + (-5.333)^2 + (-1.333)^2 + (0.667)^2 + (4.667)^2 + (8.667)^2$$
   $$= 53.773 + 28.441 + 1.777 + 0.445 + 21.781 + 75.117 = \mathbf{181.334}$$

4. **ল্যাগ-১ ক্রস-প্রোডাক্ট (লব ১):**
   - $t=2: (-5.333) \times (-7.333) = +39.107$
   - $t=3: (-1.333) \times (-5.333) = +7.109$
   - $t=4: (0.667) \times (-1.333) = -0.889$
   - $t=5: (4.667) \times (0.667) = +3.113$
   - $t=6: (8.667) \times (4.667) = +40.449$
   $$\text{লব}_1 = 39.107 + 7.109 - 0.889 + 3.113 + 40.449 = \mathbf{88.889}$$
   $$r_1 = \frac{88.889}{181.334} = \mathbf{+0.4902}$$

5. **ল্যাগ-২ ক্রস-প্রোডাক্ট (লব ২):**
   - $t=3: (-1.333) \times (-7.333) = +9.775$
   - $t=4: (0.667) \times (-5.333) = -3.557$
   - $t=5: (4.667) \times (-1.333) = -6.221$
   - $t=6: (8.667) \times (0.667) = +5.781$
   $$\text{লব}_2 = 9.775 - 3.557 - 6.221 + 5.781 = \mathbf{5.778}$$
   $$r_2 = \frac{5.778}{181.334} = \mathbf{+0.0319}$$

---

### ৩.৩ ডারবিন-লেভিনসন রিকার্শন দিয়ে PACF ($\alpha_{22}$) নির্ণয়
PACF হলো মধ্যবর্তী ল্যাগগুলোর রৈখিক প্রভাব অপসারণের পর সরাসরি কোরিলেশন।
- ল্যাগ ১-এর PACF: $\alpha_{11} = r_1 = \mathbf{0.4902}$
- ল্যাগ ২-এর PACF সমীকরণ:
  $$\alpha_{22} = \frac{r_2 - r_1^2}{1 - r_1^2}$$

#### সংখ্যা বসিয়ে হিসাব:
- $r_1^2 = (0.4902)^2 \approx 0.2403$
- লব $= 0.0319 - 0.2403 = -0.2084$
- হর $= 1 - 0.2403 = 0.7597$
$$\alpha_{22} = \frac{-0.2084}{0.7597} = \mathbf{-0.2743}$$
- **সিদ্ধান্ত:** ল্যাগ ১-এর প্রভাব সরিয়ে নিলে ল্যাগ ২-এর সরাসরি কোরিলেশন ধনাত্মক নয়, বরং ঋণাত্মক $-০.২৭৪৩$! সাধারণ ACF এই সত্যটি ধরতে পারে না।

## ৪. ফোরকাস্টিং বেসলাইনস (Baselines)

1. **Naive Forecast (Random Walk):**
   $$\hat{Y}_{t+h|t} = Y_t$$
2. **Seasonal Naive Forecast:**
   $$\hat{Y}_{t+h|t} = Y_{t+h - m(k+1)}$$
   *(যেমন: ২০২৬ সালের ডিসেম্বরের পূর্বাভাস = ২০২৫ সালের ডিসেম্বরের বাস্তব মান।)*
3. **Drift Forecast:**
   $$\hat{Y}_{t+h|t} = Y_t + h \left( \frac{Y_t - Y_1}{t - 1} \right)$$

## ৫. পরিসংখ্যানিক মডেলিং: এক্সপোনেনশিয়াল স্মুথিং, ARIMA ও SARIMA

### ৫.১ Simple Exponential Smoothing (SES) হাতে-কলমে গণনা
$$\hat{Y}_{t+1} = \alpha Y_t + (1 - \alpha) \hat{Y}_t, \quad \alpha \in [0, 1]$$
ধরি $\alpha = 0.40$, প্রকৃত মান: $Y_1 = 100, Y_2 = 110, Y_3 = 105$। প্রাথমিক মান $\hat{Y}_1 = 100$।
1. $\hat{Y}_2 = 0.40(100) + 0.60(100) = \mathbf{100.0}$
2. $\hat{Y}_3 = 0.40(110) + 0.60(100) = 44 + 60 = \mathbf{104.0}$
3. $\hat{Y}_4 = 0.40(105) + 0.60(104) = 42 + 62.4 = \mathbf{104.4}$

---

### ৫.২ Holt's Linear Trend (Double Smoothing)
ট্রেন্ডযুক্ত ডেটায় দুটি সমীকরণ যুগপৎ আপডেট হয়:
1. **Level:** $l_t = \alpha Y_t + (1 - \alpha)(l_{t-1} + b_{t-1})$
2. **Trend:** $b_t = \beta (l_t - l_{t-1}) + (1 - \beta) b_{t-1}$
3. **ফোরকাস্ট ($h$-ধাপ সামনে):** $\hat{Y}_{t+h|t} = l_t + h b_t$

---

### ৫.৩ $\text{SARIMA}(p, d, q)(P, D, Q)_s$ ব্যাকশিফট সমীকরণ
$$\Phi_P(B^s) \phi_p(B) (1 - B)^d (1 - B^s)^D Y_t = c + \Theta_Q(B^s) \theta_q(B) \epsilon_t$$
- $\phi_p(B)$: নন-সিজনাল অটোরিগ্রেসিভ বহুপদী ($1 - \phi_1 B - \dots - \phi_p B^p$)
- $\Phi_P(B^s)$: সিজনাল অটোরিগ্রেসিভ বহুপদী ($1 - \Phi_1 B^s - \dots - \Phi_P B^{Ps}$)
- $(1 - B)^d (1 - B^s)^D$: নন-সিজনাল ও সিজনাল ডিফারেন্সিং অপারেটর
- $\Theta_Q(B^s) \theta_q(B)$: মুভিং এভারেজ এরর বহুপদী

---

### ৫.৪ লাজুং-বক্স (Ljung-Box) ডায়াগনস্টিক টেস্ট
মডেল ফিট করার পর অবশিষ্ট রেসিডুয়ালে কোনো তথ্য রয়ে গেছে কিনা তা পরীক্ষা:
$$Q = T(T + 2) \sum_{k=1}^h \frac{r_k^2}{T - k} \sim \chi^2(h - p - q)$$
- যদি $p\text{-value} > 0.05$ হয়, তবে রেসিডুয়াল নিখুঁত হোয়াইট নয়েজ (মডেল সম্পূর্ণ সফল!)।

## ৬. আধুনিক ট্রি-বেসড ফোরকাস্টিং (Feature Engineering)

LightGBM বা XGBoost দিয়ে সময়-সিরিজ প্রেডিকশনের ফিচার ইঞ্জিনিয়ারিং ফ্রেমওয়ার্ক:

```
  Date         Sales (Y)   Lag_1 (Y_t-1)   Lag_12 (Y_t-12)   Rolling_Mean_3m   Fourier_Sin_1
  2026-01-01      150          140              120              143.3           +0.5000
```

### ৬.১ ফুরিয়ার টার্মস (Fourier Seasonality):
$$S_k(t) = \sin\left(\frac{2\pi k t}{P}\right), \quad C_k(t) = \cos\left(\frac{2\pi k t}{P}\right)$$
- ৩৬৫টি ক্যাটাগরিকাল ওয়ান-হট কলামের বদলে মাত্র ৩ জোড়া সাইন/কোসাইন দিয়ে জটিল বাৎসরিক সিজনালিটি স্মুথভাবে রিপ্রেজেন্ট করা যায়।

### ৬.২ মাল্টি-স্টেপ ফোরকাস্টিং আর্কিটেকচার:
1. **Recursive Strategy:** $t+1$ প্রেডিক্ট করে সেই প্রেডিকশনকে পরবর্তী ল্যাগ হিসেবে ব্যবহার করে $t+2$ প্রেডিক্ট করা (এরর চক্রবৃদ্ধি হারে বাড়ে)।
2. **Direct Strategy:** আগামী ১ থেকে ১২ মাসের প্রতিটির জন্য ১২টি স্বাধীন মডেল ট্রেন করা ($M_1, M_2, \dots, M_{12}$)। এরর জমে না, কিন্তু ট্রেনিং খরচ ১২ গুণ বাড়ে।

## ৭. ফোরকাস্ট এরর মেট্রিক্স ও প্রেডিকশন ইন্টারভ্যালস

### ৭.১ Mean Absolute Scaled Error (MASE)
$$\text{MASE} = \frac{\frac{1}{h} \sum_{t=1}^h |Y_t - \hat{Y}_t|}{\frac{1}{T - 1} \sum_{t=2}^T |Y_t - Y_{t-1}|} = \frac{\text{MAE}_{\text{Model}}}{\text{MAE}_{\text{Naive}}}$$

#### 🔢 হাতে-কলমে MASE হিসাব:
ধরি টেস্ট সেটের ৩টি মাসে মডেলের এরর $|Y - \hat{Y}| = [4, 6, 5] \implies \text{MAE}_{\text{Model}} = \frac{15}{3} = \mathbf{5.0}$।
ট্রেনিং সেটের ইন-স্যাম্পল নাইভ এরর ছিল গড়ে $\mathbf{12.5}$।
$$\text{MASE} = \frac{5.0}{12.5} = \mathbf{0.400}$$
- **ব্যাখ্যা:** $\text{MASE} = 0.40 < 1.0$ হওয়ায় মডেলটি নাইভ বেসলাইনের চেয়ে ৬০% বেশি নিখুঁত!

---

### ৭.২ Quantile Regression & Pinball Loss দিয়ে ৯০% প্রেডিকশন ইন্টারভ্যাল
$$L_q(y, \hat{y}) = \max\left( q(y - \hat{y}), (1 - q)(\hat{y} - y) \right)$$
- $q = 0.05$ দিয়ে LightGBM মডেল ট্রেন করলে সে ৫ম পার্সেন্টাইল (লোয়ার বাউন্ড) দেবে।
- $q = 0.95$ দিয়ে আরেকটি মডেল ট্রেন করলে সে ৯৫তম পার্সেন্টাইল (আপার বাউন্ড) দেবে।
- উভয়ের মধ্যবর্তী দূরত্বটিই হলো মডেলের **৯০% প্রেডিকশন ইন্টারভ্যাল**।

- **সিদ্ধান্ত:** টিকিট ৩-কে বেছে নিয়ে মানব বিশেষজ্ঞের কাছে পাঠানো হবে।

## ১০. কজাল ইনফ্যারেন্স ও কাউন্টারফ্যাকচুয়াল রিজনিং

```
                     Confounder W (গ্রাহকের বয়স ও আয়)
                            /                \
                           ▼                  ▼
                Treatment T (ডিসকাউন্ট অফার)    Outcome Y (চার্ন করবে কি না)
```

### ১০.১ রুবিনের পটেনশিয়াল আউটকামস ও ATE:
$$\text{Average Treatment Effect (ATE)} = \mathbb{E}[Y(1) - Y(0)]$$

### ১০.২ Inverse Probability Weighting (IPW) হাতে-কলমে ৪ রোগীর ডেটায় হিসাব:

| রোগী ($i$) | বয়স ($X$) | ট্রিটমেন্ট ($T$) | প্রোপেনসিটি $e(X) = P(T=1|X)$ | আউটকাম ($Y$) | IPW ওয়েট $w = \frac{T}{e} + \frac{1-T}{1-e}$ | ওজনযুক্ত আউটকাম ($w \cdot Y$) |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| ১ | ৬০ | ১ | $0.80$ | ১০ | $\frac{1}{0.80} = \mathbf{1.25}$ | $1.25 \times 10 = 12.5$ |
| ২ | ২৫ | ১ | $0.20$ | ১২ | $\frac{1}{0.20} = \mathbf{5.00}$ | $5.00 \times 12 = 60.0$ |
| ৩ | ৬৫ | ০ | $0.80$ | ৫ | $\frac{1}{1 - 0.80} = \frac{1}{0.20} = \mathbf{5.00}$ | $5.00 \times 5 = 25.0$ |
| ৪ | ৩০ | ০ | $0.20$ | ৭ | $\frac{1}{1 - 0.20} = \frac{1}{0.80} = \mathbf{1.25}$ | $1.25 \times 7 = 8.75$ |

- ট্রিটমেন্ট গ্রুপের ওজনযুক্ত গড়: $\bar{Y}_1 = \frac{12.5 + 60.0}{1.25 + 5.00} = \frac{72.5}{6.25} = \mathbf{11.60}$
- কন্ট্রোল গ্রুপের ওজনযুক্ত গড়: $\bar{Y}_0 = \frac{25.0 + 8.75}{5.00 + 1.25} = \frac{33.75}{6.25} = \mathbf{5.40}$
$$\text{ATE} = \bar{Y}_1 - \bar{Y}_0 = 11.60 - 5.40 = \mathbf{+6.20}$$
- **সিদ্ধান্ত:** কনফাউন্ডার বয়স নিয়ন্ত্রণ করার পর দেখা গেল ট্রিটমেন্টের কারণে আউটকাম গড়ে ৬.২ একক বৃদ্ধি পায়!

---

### ১০.৩ আপলিফট মডেলিং (Uplift Meta-Learners):
1. **S-Learner (Single Model):** একটি একক মডেল যেখানে ট্রিটমেন্ট $T$ একটি সাধারণ ইনপুট ফিচার: $\hat{\tau}(x) = f(x, 1) - f(x, 0)$।
2. **T-Learner (Two Models):** ট্রিটমেন্টের জন্য আলাদা মডেল $M_1$ এবং কন্ট্রোলের জন্য আলাদা মডেল $M_0$:
   $$\hat{\tau}(x) = M_1(x) - M_0(x)$$
3. **X-Learner:** চরম ভারসাম্যহীন ট্রিটমেন্ট গ্রুপে ক্রস-ওভার রেসিডুয়াল ফিট করে সেরা পারফরম্যান্স দেয়।

### 🎓 পাস কন্ডিশন ডিফেন্স ও ভাইভা প্রশ্নোত্তর (Pass Condition Defense):

#### প্রশ্ন: টাইম-সিরিজ ডেটাতে সাধারণ Random K-Fold স্প্লিট কেন সম্পূর্ণ নিষিদ্ধ এবং কেন টেম্পোরাল ভ্যালিডেশন আবশ্যক?
**উত্তর ও গাণিতিক প্রমাণ:**
টাইম-সিরিজে প্রতিটি সারি অপর সারির সাথে অটোকোরিলেটেড ($Y_t$ সরাসরি $Y_{t-1}$-এর ওপর নির্ভরশীল)।
যদি সাধারণ র‍্যান্ডম স্প্লিট করা হয়:
- টেস্ট সেটে যাবে ১৫ তারিখের ডেটা ($t=15$)।
- কিন্তু ট্রেইনিং সেটে চলে আসবে ১৪ ও ১৬ তারিখের ডেটা!
- মডেল ভবিষ্যতের ডেটা দেখে ফেলার সুযোগ পায় (**Lookahead Bias** বা **Data Snooping**)। মডেল ১৪ ও ১৬ তারিখের গড় বের করে অবলীলায় ১৫ তারিখের মান ১০০% নিখুঁত বলে দেবে।
- ফলে ভ্যালিডেশন সেটে হয়তো **৯৯% অ্যাকুরেসি বা $R^2 = 0.99$** দেখা যাবে।
- কিন্তু বাস্তব প্রোডাকশনে যখন মডেল ডিপ্লয় হবে, তখন তার কাছে ভবিষ্যতের ডেটা থাকবে না! ফলে প্রোডাকশনে মডেলের এরর ৫০০% বৃদ্ধি পেয়ে সিস্টেম ক্র্যাশ করবে।
- **একমাত্র সমাধান:** কঠোরভাবে **Temporal Walk-Forward Validation (Expanding / Rolling Window)** ব্যবহার করা, যেখানে ট্রেইনিং সর্বদা অতীতের ডেটায় সীমাবদ্ধ থাকবে এবং প্রেডিকশন কেবল ভবিষ্যতে ঘটবে।

## ১২. স্ক্র্যাচ পাইথন ও ফোরকাস্টিং প্রোডাকশন কোড

```python
"""
production_time_series_pipeline.py
Complete Time-Series Feature Engineering, Walk-Forward CV & LightGBM Pipeline
"""
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import adfuller

def build_time_series_features(df: pd.DataFrame, target_col: str):
    feat_df = df.copy()
    feat_df['timestamp'] = pd.to_datetime(feat_df['timestamp'])
    feat_df = feat_df.sort_values('timestamp').reset_index(drop=True)

    # ১. ক্যালেন্ডার ও ফুরিয়ার ফিচার
    feat_df['month'] = feat_df['timestamp'].dt.month
    feat_df['sin_month'] = np.sin(2 * np.pi * feat_df['month'] / 12.0)
    feat_df['cos_month'] = np.cos(2 * np.pi * feat_df['month'] / 12.0)

    # ২. ল্যাগ ফিচারস
    feat_df['lag_1'] = feat_df[target_col].shift(1)
    feat_df['lag_12'] = feat_df[target_col].shift(12)

    # ৩. রোলিং উইন্ডো
    feat_df['rolling_mean_3'] = feat_df[target_col].shift(1).rolling(3).mean()
    feat_df['rolling_mean_6'] = feat_df[target_col].shift(1).rolling(6).mean()

    return feat_df.dropna().reset_index(drop=True)

def temporal_walk_forward_cv(df: pd.DataFrame, min_train_size: int = 24, horizon: int = 1):
    n_samples = len(df)
    for split_idx in range(min_train_size, n_samples - horizon + 1):
        train_idx = list(range(0, split_idx))
        test_idx = list(range(split_idx, split_idx + horizon))
        yield train_idx, test_idx

if __name__ == "__main__":
    dates = pd.date_range(start="2023-01-01", periods=36, freq="MS")
    trend = np.linspace(50, 120, 36)
    seasonality = 20 * np.sin(2 * np.pi * np.arange(36) / 12.0)
    noise = np.random.normal(0, 3, 36)
    sales = trend + seasonality + noise

    raw_data = pd.DataFrame({'timestamp': dates, 'sales': sales})
    processed = build_time_series_features(raw_data, 'sales')

    print(f"প্রসেসড ফিচারের আকার: {processed.shape}")
    print("\nফিচার টেবিলের নমুনা:")
    print(processed[['timestamp', 'sales', 'lag_1', 'lag_12', 'rolling_mean_3']].head(3))

    folds = list(temporal_walk_forward_cv(processed, min_train_size=18, horizon=1))
    print(f"\nমোট সফল টেম্পোরাল ফোল্ড সংখ্যা: {len(folds)} (জিরো লিকেজ নিশ্চিত!)")
```
