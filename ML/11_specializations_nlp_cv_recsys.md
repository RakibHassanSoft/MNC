# ২. স্পেশালাইজেশন ১: ন্যাচারাল ল্যাঙ্গুয়েজ প্রসেসিং (NLP)

টেক্সট ডেটা সম্পূর্ণ আনস্ট্রাকচার্ড এবং ডিসক্রিট (Discrete)। NLP-এর মূল চ্যালেঞ্জ হলো ডিসক্রিট শব্দ বা টোকেনকে এমন কন্টিনিউয়াস ভেক্টর স্পেসে ম্যাপ করা যাতে শব্দের অর্থগত (Semantic) ও ব্যাকরণগত (Syntactic) সম্পর্ক সংরক্ষিত থাকে।

```
Raw Text Document
       │
       ▼
[ Preprocessing & Cleaning ] ──► Lowercasing, Regex, Normalization, Unicode handling
       │
       ▼
[ Subword Tokenization ]    ──► Byte-Pair Encoding (BPE) / WordPiece (No Out-of-Vocabulary)
       │
       ▼
[ Dense Vector Embeddings ] ──► TF-IDF / Word2Vec / GloVe / Transformer Contextualized Embeddings
       │
       ▼
[ Deep Architecture ]       ──► BiLSTM + CRF / Self-Attention Transformer Encoders (BERT)
       │
       ▼
[ Downstream Task ]         ──► Classification / NER / Extractive QA / Semantic Similarity
```

### ২.১ টেক্সট প্রি-প্রসেসিং ও সাবওয়ার্ড টোকেনাইজেশন
ঐতিহ্যগত স্পেস-ভিত্তিক টোকেনাইজেশনে সবচেয়ে বড় বিপর্যয় হলো **Out-of-Vocabulary (OOV)** সমস্যা। নতুন কোনো শব্দ আসলেই মডেল সেটিকে `[UNK]` (Unknown) টোকেনে রূপান্তরিত করে, ফলে অর্থ হারিয়ে যায়।
আধুনিক এনএলপির সমাধান হলো **Subword Tokenization (BPE - Byte Pair Encoding / WordPiece / SentencePiece)**।

#### 🔬 বাইট-পেয়ার এনকোডিং (BPE) অ্যালগরিদম কীভাবে কাজ করে?
BPE প্রতিটি শব্দকে ক্যারেক্টার স্তরে বিভক্ত করে শুরু করে এবং ট্রেইনিং করপাসে সবচেয়ে বেশি বার পাশাপাশি আসা ক্যারেক্টার বা সাবওয়ার্ড জোড়াকে একটি নতুন টোকেনে মার্জ (Merge) করে।

#### 🔢 হাতে-কলমে BPE মার্জিং সিমুলেশন:
ধরি আমাদের ছোট করপাসে ৪টি শব্দ এবং তাদের ফ্রিকোয়েন্সি রয়েছে:
- `"low"` : ৫ বার
- `"lower"` : ২ বার
- `"newest"` : ৬ বার
- `"widest"` : ৩ বার

**ধাপ ১: ইনিশিয়াল ভোকাবুলারি ও ক্যারেক্টার স্প্লিট (শব্দের শেষে এন্ড-অফ-ওয়ার্ড মার্কার `_` যুক্ত করে):**
```
ভোকাবুলারি: { 'l', 'o', 'w', 'e', 'r', 'n', 's', 't', 'i', 'd', '_' }
শব্দসমূহ:
  5 ×  l  o  w  _
  2 ×  l  o  w  e  r  _
  6 ×  n  e  w  e  s  t  _
  3 ×  w  i  d  e  s  t  _
```

**ধাপ ২: পাশাপাশি থাকা প্রতিটি জোড়ার (Bigram) ফ্রিকোয়েন্সি গণনা:**
- `('e', 's')`: "newest" এ ৬ বার + "widest" এ ৩ বার = **৯ বার**
- `('s', 't')`: "newest" এ ৬ বার + "widest" এ ৩ বার = **৯ বার**
- `('l', 'o')`: "low" এ ৫ বার + "lower" এ ২ বার = ৭ বার
- `('o', 'w')`: "low" এ ৫ বার + "lower" এ ২ বার = ৭ বার

**ধাপ ৩: সর্বোচ্চ ফ্রিকোয়েন্সির জোড়া মার্জ করা (Merge 1: `('e', 's')` $\to$ `'es'`):**
নতুন ভোকাবুলারি: `{..., 'es'}`
```
  5 ×  l  o  w  _
  2 ×  l  o  w  e  r  _
  6 ×  n  e  w  es  t  _
  3 ×  w  i  d  es  t  _
```

**ধাপ ৪: পরবর্তী সর্বোচ্চ জোড়া মার্জ করা (Merge 2: `('es', 't')` $\to$ `'est'`):**
`('es', 't')` জোড়া এসেছে: ৬ + ৩ = **৯ বার**। নতুন টোকেন: `'est'`।
```
  5 ×  l  o  w  _
  2 ×  l  o  w  e  r  _
  6 ×  n  e  w  est  _
  3 ×  w  i  d  est  _
```
**ফলাফল:** এখন টেস্ট টাইমে যদি একটি সম্পূর্ণ নতুন শব্দ `"lowest"` আসে, মডেল এটিকে `[UNK]` বলবে না! সে এটিকে সাবওয়ার্ড দিয়ে ভাঙবে: `['low', 'est']`। এর ফলে ভোকাবুলারি সাইজ ছোট থাকে ($30,000 - 50,000$ টোকেন) কিন্তু যেকোনো অজানা শব্দকে অর্থপূর্ণভাবে রিপ্রেজেন্ট করা যায়।

### ২.২ ট্র্যাডিশনাল টেক্সট ফিচার: BoW ও TF-IDF

#### ১. Bag of Words (BoW):
ডকুমেন্টে শব্দের উপস্থিতির কাউন্ট ম্যাট্রিক্স। 
- *সীমাবদ্ধতা:* বাক্যের ব্যাকরণ ও শব্দের ক্রম (Word Order) সম্পূর্ণ হারিয়ে যায় এবং ম্যাট্রিক্স অত্যন্ত স্পার্স (Sparse) ও উচ্চমাত্রিক হয়।

#### ২. Term Frequency - Inverse Document Frequency (TF-IDF):
একটি শব্দ কোনো নির্দিষ্ট ডকুমেন্টে কত ঘন ঘন এসেছে (TF) এবং পুরো করপাসে শব্দটি কতটা বিরল বা গুরুত্বপূর্ণ (IDF), তার গুণফল।
$$\text{TF}(t, d) = \frac{f_{t, d}}{\sum_{t' \in d} f_{t', d}}$$
$$\text{IDF}(t, D) = \ln\left( \frac{N + 1}{\text{DF}(t) + 1} \right) + 1$$
$$\text{TF-IDF}(t, d, D) = \text{TF}(t, d) \times \text{IDF}(t, D)$$
যেখানে $N$ = মোট ডকুমেন্ট সংখ্যা, $\text{DF}(t)$ = শব্দটি যতগুলো ডকুমেন্টে আছে তার সংখ্যা (মসৃণতার জন্য স্মুথিং $+1$ যোগ করা হয়েছে)।

#### 🔢 হাতে-কলমে ৩টি ডকুমেন্টে TF-IDF হিসাব:
করপাস ($N = 3$):
- **Doc 1:** "ML is powerful" (৩ শব্দ)
- **Doc 2:** "ML is simple" (৩ শব্দ)
- **Doc 3:** "AI is ML" (৩ শব্দ)

ধরি আমরা শব্দ **"powerful"** এবং **"is"** এর জন্য Doc 1-এ TF-IDF বের করব:

**১. IDF গণনা:**
- মোট ডকুমেন্ট $N = 3$
- `"is"` শব্দটি ৩টি ডকুমেন্টেই আছে ($\text{DF} = 3$):
  $$\text{IDF}(\text{"is"}) = \ln\left( \frac{3 + 1}{3 + 1} \right) + 1 = \ln(1) + 1 = 0 + 1 = \mathbf{1.0}$$
- `"powerful"` শব্দটি কেবল Doc 1-এ আছে ($\text{DF} = 1$):
  $$\text{IDF}(\text{"powerful"}) = \ln\left( \frac{3 + 1}{1 + 1} \right) + 1 = \ln(2) + 1 = 0.693 + 1 = \mathbf{1.693}$$

**২. Doc 1-এ TF গণনা:**
- $\text{TF}(\text{"is"}, \text{Doc 1}) = \frac{1}{3} \approx \mathbf{0.333}$
- $\text{TF}(\text{"powerful"}, \text{Doc 1}) = \frac{1}{3} \approx \mathbf{0.333}$

**৩. ফাইনাল TF-IDF স্কোর (Doc 1):**
- $\text{TF-IDF}(\text{"is"}) = 0.333 \times 1.0 = \mathbf{0.333}$
- $\text{TF-IDF}(\text{"powerful"}) = 0.333 \times 1.693 = \mathbf{0.564}$
- *ব্যাখ্যা:* `"powerful"` শব্দটি বিরল এবং শুধুমাত্র এই ডকুমেন্টের স্বাতন্ত্র্য বোঝায়, তাই গাণিতিকভাবে এর গুরুত্ব (০.৫৬৪) সাধারণ স্টপ-ওয়ার্ড `"is"` (০.৩৩৩) এর চেয়ে অনেক বেশি!

### ২.৩ ডিস্ট্রিবিউটেড ওয়ার্ড এমবেডিংস: Word2Vec ও GloVe

#### ১. ডিস্ট্রিবিউশনাল হাইপোথিসিস (Firth, 1957):
> *"You shall know a word by the company it keeps."* — একই ধরনের কনটেক্সটে ব্যবহৃত শব্দগুলোর অর্থগত অবস্থান ভেক্টর স্পেসে কাছাকাছি হওয়া উচিত।

```
    CBOW (Continuous Bag of Words)                   Skip-gram Architecture
    Context Words ──► Predict Target Word           Target Word ──► Predict Context Words
    
    w(t-2) ──┐                                                     ┌──► w(t-2)
    w(t-1) ──┼──► [ Sum / Average ] ──► w(t)              w(t) ────┼──► w(t-1)
    w(t+1) ──┤                                                     ├──► w(t+1)
    w(t+2) ──┘                                                     └──► w(t+2)
```

#### ২. Skip-gram উইথ নেগেটিভ স্যাম্পলিং (SGNS) লস সমীকরণ:
সাধারণ সফটম্যাক্স ব্যবহারে সম্পূর্ণ ভোকাবুলারি $|V|$ (যেমন: ১,০০০,০০০ শব্দ) দিয়ে নরমালাইজ করতে হয়, যার কম্পিউটেশনাল জটিলতা $O(|V|)$।
Mikolov et al. (2013) **Negative Sampling** প্রস্তাব করেন, যা সমস্যাটিকে লজিস্টিক বাইনারি ক্লাসিফিকেশনে রূপান্তরিত করে ($O(K)$, যেখানে $K \approx 5-20$ টি রেন্ডম নেগেটিভ শব্দ):
$$\mathcal{L}_{\text{Skip-gram}} = \sum_{t=1}^T \sum_{-c \le j \le c, j \neq 0} \left[ \ln \sigma(\mathbf{v}'^\top_{w_{t+j}} \mathbf{v}_{w_t}) + \sum_{k=1}^K \mathbb{E}_{w_{i,k} \sim P_n(w)} \left[ \ln \sigma(-\mathbf{v}'^\top_{w_{i,k}} \mathbf{v}_{w_t}) \right] \right]$$
- $\mathbf{v}_{w_t}$: টার্গেট শব্দের ইনপুট ভেক্টর।
- $\mathbf{v}'_{w_{t+j}}$: প্রকৃত কনটেক্সট শব্দের আউটপুট ভেক্টর।
- $\mathbf{v}'_{w_{i,k}}$: নয়েজ ডিস্ট্রিবিউশন $P_n(w)$ থেকে স্যাম্পল করা নেগেটিভ শব্দ (যা কনটেক্সটে নেই)।
- $P_n(w) = \frac{U(w)^{3/4}}{\sum_w U(w)^{3/4}}$: শব্দের ফ্রিকোয়েন্সির $\frac{3}{4}$ পাওয়ার নেওয়া হয় যাতে বিরল শব্দগুলোও পর্যাপ্ত স্যাম্পল হওয়ার সুযোগ পায়।

#### ৩. GloVe (Global Vectors for Word Representation - Pennington et al., Stanford):
Word2Vec শুধুমাত্র লোকাল উইন্ডো দেখে, গ্লোবাল স্ট্যাটিস্টিকস ব্যবহার করে না। GloVe সম্পূর্ণ করপাসের গ্লোবাল কো-অকারেন্স ম্যাট্রিক্স $X_{ij}$ এর অনুপাতকে সরাসরি লিনিয়ার ল্যাটেন্ট স্পেসে ফিট করে:
$$J = \sum_{i,j=1}^V f(X_{ij}) \left( \mathbf{w}_i^\top \tilde{\mathbf{w}}_j + b_i + \tilde{b}_j - \ln X_{ij} \right)^2$$
যেখানে ওয়েটিং ফাংশন $f(x) = \min\left(1, (x/x_{\max})^\alpha\right)$ অতি-ঘন ঘন শব্দগুলোকে (যেমন: "the", "a") মাত্রাতিরিক্ত গুরুত্ব দেওয়া থেকে আটকায়।

---

### ২.৪ সিকোয়েন্স মডেলিং: BiLSTM + CRF আর্কিটেকচার (NER)
টোকেন ক্লাসিফিকেশন যেমন **Named Entity Recognition (NER)** এ কেবল বর্তমান শব্দের ওপর ভিত্তি করে সিদ্ধান্ত নেওয়া বিপজ্জনক। যেমন: `"New"` শব্দটি স্থান নাকি সংগঠন তা নির্ভর করে পরবর্তী শব্দের ওপর (`"New York"` বনাম `"New York Times"`):
1. **Bidirectional LSTM:** পূর্ববর্তী ও পরবর্তী উভয় দিক থেকে কনটেক্সট ক্যাপচার করে হিডেন স্টেট তৈরি করে: $h_t = [\overrightarrow{h_t}; \overleftarrow{h_t}]$।
2. **Conditional Random Field (CRF) লেয়ার:** টোকেন লেভেলের সিদ্ধান্তের বদলে সম্পূর্ণ সিকোয়েন্স লেভেলে গ্লোবাল অপটিমাল ট্যাগ নির্ধারণ করে। 
   - CRF একটি ট্রানজিশন ম্যাট্রিক্স $A_{i,j}$ শিখে যা নিশ্চিত করে যে অবৈধ ট্যাগ সিকোয়েন্স (যেমন: `B-PER` এর পর সরাসরি `I-LOC`) কখনো প্রেডিক্ট হতে পারবে না।

---

### ২.৫ প্রি-ট্রেইন্ড ল্যাঙ্গুয়েজ মডেল ও ট্রান্সফরমার ফাইন-টিউনিং (BERT)
BERT (Bidirectional Encoder Representations from Transformers) মডেল দুটি সেলফ-সুপারভাইজড টাস্কে প্রি-ট্রেইন করা হয়:
1. **Masked Language Model (MLM):** ইনপুটের ১৫% টোকেন নির্বাচন করা হয়:
   - ৮০% ক্ষেত্রে `[MASK]` টোকেন দিয়ে প্রতিস্থাপন।
   - ১০% ক্ষেত্রে একটি রেন্ডম শব্দ দিয়ে প্রতিস্থাপন।
   - ১০% ক্ষেত্রে অপরিবর্তিত রাখা হয়।
   - মডেলকে বাইডিরেকশনাল কনটেক্সট দেখে মূল শব্দটি প্রেডিক্ট করতে হয়।
2. **Next Sentence Prediction (NSP):** দুটি বাক্য $A$ ও $B$ এর মধ্যে $B$ কি আসলেই $A$-এর পরবর্তী বাক্য কিনা তা বাইনারি ক্লাসিফাই করা।

#### ফাইন-টিউনিং মেকানিক্স (Downstream Fine-Tuning):
প্রি-ট্রেইন্ড BERT-এর ওপরের আউটপুট থেকে বিশেষ `[CLS]` টোকেনের এমবেডিং $\mathbf{h}_{[CLS]} \in \mathbb{R}^{768}$ নেওয়া হয়। এরপর একটি ছোট লিনিয়ার লেয়ার $W \in \mathbb{R}^{C \times 768}$ এবং সফটম্যাক্স বসিয়ে নির্দিষ্ট ডাউনস্ট্রিম টাস্কের (যেমন সাপোর্ট টিকেট ক্যাটাগরি) জন্য সামান্য লার্নিং রেটে ($\eta \approx 2 \times 10^{-5}$) পুরো নেটওয়ার্ক এন্ড-টু-এন্ড ফাইন-টিউন করা হয়।

# ৩. স্পেশালাইজেশন ২: কম্পিউটার ভিশন (CV)

ডিজিটাল ছবি হলো পিক্সেল ইনটেনসিটির ৩-মাত্রিক টেনসর: $H \times W \times C$ (উচ্চতা, প্রস্থ, কালার চ্যানেল Red-Green-Blue)।

```
Input Image [3, H, W] ──► Normalization ──► Augmentations (Mixup / CutMix)
       │
       ▼
Feature Extraction Backbone (ResNet / EfficientNet / ViT)
       │
       ├───────────────────────────────┬───────────────────────────────┐
       ▼                               ▼                               ▼
[ Classification Head ]     [ Object Detection Head ]       [ Segmentation Head ]
Class Logits [Num_Classes]   Boxes [x, y, w, h] + Class      Pixel Mask [1, H, W]
```

### ৩.১ ডিজিটাল ইমেজ টেনসর ও পার-চ্যানেল নরমালাইজেশন
- **চ্যানেল রি-অর্ডারিং:** OpenCV ছবি লোড করে **BGR** ফরম্যাটে, কিন্তু PyTorch ও আধুনিক ফ্রেমওয়ার্ক প্রত্যাশা করে **RGB** এবং টেনসর শেইপ হতে হয় $[C, H, W]$ (Channels-First)।
- **স্ট্যান্ডার্ড ইমেজনেট নরমালাইজেশন:**
  $$x_{\text{norm}}^{(c)} = \frac{x^{(c)} / 255.0 - \mu_c}{\sigma_c}$$
  ImageNet প্যারামিটার: $\boldsymbol{\mu} = [0.485, 0.456, 0.406], \quad \boldsymbol{\sigma} = [0.229, 0.224, 0.225]$। এটি অপটিমাইজেশন ল্যান্ডস্কেপকে গোলাকার করে গ্রেডিয়েন্ট ডিসেন্টকে দ্রুত কনভার্জ করায়।

---

### ৩.২ আধুনিক ডেটা অগমেন্টেশন (Mixup ও CutMix)
ঐতিহ্যগত ক্রপ বা ফ্লিপের বাইরে আধুনিক মডেলের জেনারেলাইজেশন বাড়াতে দুটি স্টেট-অফ-দ্য-আর্ট কৌশল ব্যবহৃত হয়:

#### ১. Mixup (Zhang et al., 2018):
দুটি ভিন্ন ক্লাসের ছবি ও তাদের ওয়ান-হট লেবেলকে উত্তল সমন্বয়ে (Convex Combination) মিশিয়ে দেওয়া হয়:
$$\tilde{x} = \lambda x_i + (1 - \lambda) x_j, \quad \tilde{y} = \lambda y_i + (1 - \lambda) y_j, \quad \lambda \sim \text{Beta}(\alpha, \alpha)$$
- মডেল কঠোর ডিসিশন বাউন্ডারির বদলে মসৃণ লিনিয়ার ইন্টারপোলেশন শেখে, যা ওভারফিটিং ও অ্যাডভারসারিয়াল অ্যাটাক প্রতিরোধ করে।

#### ২. CutMix (Yun et al., 2019):
ছবি $A$-এর একটি নির্দিষ্ট চতুর্ভুজ অংশ কেটে ফেলে সেখানে ছবি $B$-এর অংশ পেস্ট করা হয়।
- কাট বক্সের অনুপাত $\frac{w \cdot h}{W \cdot H} = 1 - \lambda$ হলে লেবেল হয়: $\tilde{y} = \lambda y_A + (1 - \lambda) y_B$।
- মডেল আংশিক অবজেক্ট দেখেই পুরো ক্লাসের বৈশিষ্ট্য চিনতে পারে (Occlusion Robustness)।

---

### ৩.৩ কনভোল্যুশনাল নেটওয়ার্কের বিবর্তন ও কম্পাউন্ড স্কেলিং
1. **ResNet (He et al., 2015):** রেসিডুয়াল স্কিপ কানেকশন $y = \mathcal{F}(x, \{W_i\}) + x$ গ্রেডিয়েন্টকে কোনো অবক্ষয় ছাড়াই শত শত লেয়ার দিয়ে প্রবাহিত হতে দেয়।
2. **EfficientNet (Tan & Le, 2019):** নেটওয়ার্কের গভীরতা ($d$), প্রস্থ ($w$), এবং ইনপুট রেজোলিউশন ($r$) ইচ্ছামতো না বাড়িয়ে **Compound Coefficient ($\phi$)** দ্বারা সুনির্দিষ্ট অনুপাতে স্কেল করা:
   $$\text{Depth}: d = \alpha^\phi, \quad \text{Width}: w = \beta^\phi, \quad \text{Resolution}: r = \gamma^\phi$$
   শর্ত: $\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2$ (যাতে মোট FLOPS $2^\phi$ হারে বাড়ে)। ফলে অত্যন্ত অল্প প্যারামিটারে সর্বোচ্চ নির্ভুলতা অর্জিত হয়।

---

### ৩.৪ অবজেক্ট ডিটেকশন মেকানিক্স: বাউন্ডিং বক্স, IoU ও NMS

```
           Ground Truth (B_gt)
           ┌──────────────────────┐
           │                      │
           │         Intersection │
           │         ┌────────────┼─────────┐
           │         │  OVERLAP   │         │
           └─────────┼────────────┘         │
                     │                      │
                     └──────────────────────┘
                     Predicted Box (B_p)
```

#### ১. Intersection over Union (IoU) গাণিতিক সূত্র:
$$\text{IoU} = \frac{\text{Area}(B_p \cap B_{gt})}{\text{Area}(B_p \cup B_{gt})} = \frac{\text{Area}(B_p \cap B_{gt})}{\text{Area}(B_p) + \text{Area}(B_{gt}) - \text{Area}(B_p \cap B_{gt})}$$

#### 🔢 হাতে-কলমে বাস্তব সংখ্যাভিত্তিক IoU হিসাব:
ধরি ইমেজ প্লেনে দুটি বাউন্ডিং বক্স দেওয়া আছে $(x_1, y_1, x_2, y_2)$ ফরম্যাটে:
- **গ্রাউন্ড ট্রুথ বক্স ($B_{gt}$):** $[20, 20, 80, 80]$
- **প্রেডিক্টেড বক্স ($B_p$):** $[40, 40, 100, 100]$

**ধাপ ১: ক্ষেত্রফল গণনা:**
- $\text{Area}(B_{gt}) = (80 - 20) \times (80 - 20) = 60 \times 60 = \mathbf{3600}$
- $\text{Area}(B_p) = (100 - 40) \times (100 - 40) = 60 \times 60 = \mathbf{3600}$

**ধাপ ২: ইন্টারসেকশন (Overlap) কোঅর্ডিনেট ও ক্ষেত্রফল:**
- $x_{\text{left}} = \max(20, 40) = 40$
- $y_{\text{top}} = \max(20, 40) = 40$
- $x_{\text{right}} = \min(80, 100) = 80$
- $y_{\text{bottom}} = \min(80, 100) = 80$
- প্রস্থ = $80 - 40 = 40$, উচ্চতা = $80 - 40 = 40$
- $\text{Area}(B_p \cap B_{gt}) = 40 \times 40 = \mathbf{1600}$

**ধাপ ৩: ইউনিয়ন ক্ষেত্রফল ও IoU:**
- $\text{Area}(B_p \cup B_{gt}) = 3600 + 3600 - 1600 = \mathbf{5600}$
- $$\text{IoU} = \frac{1600}{5600} = \frac{16}{56} = \frac{2}{7} \approx \mathbf{0.2857}$$
- *সিদ্ধান্ত:* যেহেতু $\text{IoU} = 0.286 < 0.50$, তাই স্ট্যান্ডার্ড পাস কন্ডিশন অনুযায়ী এটি **False Positive** হিসেবে বাতিল হবে।

#### ২. Non-Maximum Suppression (NMS) অ্যালগরিদম:
ডিটেকশন মডেলগুলো একটিমাত্র অবজেক্টের জন্য ডজন ডজন ওভারল্যাপিং বক্স প্রেডিক্ট করে। NMS ডুপ্লিকেট দূর করে:
1. সকল প্রেডিক্টেড বক্সকে কনফিডেন্স স্কোর অনুযায়ী বড় থেকে ছোট ক্রমানুসারে সাজানো হয়।
2. সর্বোচ্চ স্কোরের বক্স $M$ নির্বাচন করে ফাইনাল তালিকায় যুক্ত করা হয়।
3. অবশিষ্ট সকল বক্সের সাথে $M$-এর IoU বের করা হয়।
4. যদি $\text{IoU}(M, B_i) > \text{Threshold}$ (সাধারণত $0.5$) হয়, তবে $B_i$-কে চিরতরে মুছে ফেলা হয়।
5. সমস্ত বক্স প্রসেস না হওয়া পর্যন্ত প্রক্রিয়াটি চলতে থাকে।

### ৩.৬ সেগমেন্টেশন ও ভিশন ট্রান্সফরমার (ViT)
1. **U-Net (Ronneberger et al.):** এনকোডারের ডাউনস্যাম্পলিং পাথে কনটেক্সট ক্যাপচার করে এবং ডিকোডারের আপস্যাম্পলিং পাথে হুবহু রেজোলিউশনে সেগমেন্টেশন মাস্ক তৈরি করে। **Skip Connections** এনকোডারের ফাইন-গ্রেইনড স্থানিক তথ্য সরাসরি ডিকোডারে পৌঁছে দেয়।
2. **Vision Transformer (ViT - Dosovitskiy et al., 2020):**
   - ইমেজ $X \in \mathbb{R}^{H \times W \times C}$-কে $P \times P$ (যেমন $16 \times 16$) আকারের নন-ওভারল্যাপিং প্যাচে কাটা হয়।
   - প্যাচ সংখ্যা: $N = \frac{H \cdot W}{P^2}$। প্রতিটি প্যাচকে ফ্ল্যাটেন করে লিনিয়ার প্রজেকশন ম্যাট্রিক্স দিয়ে $D$-মাত্রিক ভেক্টরে রূপান্তর করা হয়।
   - একটি লার্নেবল `[CLS]` টোকেন এবং 1D পজিশনাল এমবেডিং যুক্ত করে সাধারণ ট্রান্সফরমার ব্লকে পাঠানো হয়। কোনো কনভোলিউশন ছাড়াই এটি বৈশ্বিক কনটেক্সট শেখে।

# ৪. স্পেশালাইজেশন ৩: রেকমেন্ডেশন সিস্টেম (RecSys)

রেকমেন্ডেশন সিস্টেম হলো প্রযুক্তি বিশ্বের সবচেয়ে লাভজনক এমএল স্পেশালাইজেশন। Netflix-এর ৮০% ওয়াচটাইম এবং Amazon-এর ৩৫% কেনাকাটা আসে রেকমেন্ডার অ্যালগরিদম থেকে।

```
Millions of Items (Catalog)
       │
       ▼  [ Stage 1: Retrieval / Candidate Generation ] (Two-Tower / Matrix Factorization)
Hundreds of Candidates (Latency: < 10ms)
       │
       ▼  [ Stage 2: Heavy Scoring & Ranking ] (DLRM / Deep & Cross Network - DCN)
Top 50 Scored Items (Latency: < 30ms)
       │
       ▼  [ Stage 3: Re-ranking & Diversity Filters ] (Deduplication, Freshness, Fair Share)
Final Top 10 Recommendations ──► User Device Screen
```

---

### ৪.১ রেকমেন্ডার আর্কিটেকচার ফ্রেমওয়ার্ক
1. **পপুলারিটি বেসলাইন (Popularity-Based):** সর্বাধিক ভিউ বা বিক্রিত আইটেম দেখানো। কোনো পার্সোনালাইজেশন নেই, তবে এটি নতুন ইউজারের জন্য অপরিহার্য বেসলাইন।
2. **কনটেন্ট-বেসড (Content-Based):** ইউজারের পূর্ববর্তী পছন্দের আইটেমগুলোর মেটাডেটা (জনরা, ডিরেক্টর, ট্যাগ) প্রোফাইলের সাথে নতুন আইটেমের মেটাডেটার সাদৃশ্য বের করা।
3. **কোলাবোরেটিভ ফিল্টারিং (Collaborative Filtering):** কোনো মেটাডেটার প্রয়োজন নেই। সমষ্টিগত ইউজার আচরণের সাদৃশ্য (Crowd Wisdom) থেকে রেকমেন্ডেশন তৈরি করা।

---

### ৪.২ কোলাবোরেটিভ ফিল্টারিং: বাস্তব সংখ্যাভিত্তিক রেটিং প্রেডিকশন
ধরি ৪ জন ইউজার ও ৩টি মুভির একটি রেটিং ম্যাট্রিক্স $R$ রয়েছে (১ থেকে ৫ স্কেলে, $0$ মানে দেখেনি):

| ইউজার | মুভি ১ (Sci-Fi) | মুভি ২ (Space) | মুভি ৩ (Romance) |
| :--- | :---: | :---: | :---: |
| **User A** | $5$ | $4$ | $1$ |
| **User B** | $4$ | $5$ | $1$ |
| **User C** | $1$ | $1$ | $5$ |
| **User D (Target)** | $5$ | $?$ | $1$ |

**লক্ষ্য:** ইউজার D কি মুভি ২ পছন্দ করবে? ($r_{D, 2}$ প্রেডিক্ট করতে হবে)।

#### ১. ইউজার D-এর সাথে অন্যদের কোসাইন সাদৃশ্য গণনা (কমন রেটিং মুভি ১ ও ৩-এর ওপর):
- User D ভেক্টর: $\mathbf{u}_D = [5, 1]$
- User A ভেক্টর: $\mathbf{u}_A = [5, 1]$
  $$\text{Sim}(D, A) = \frac{5(5) + 1(1)}{\sqrt{5^2 + 1^2} \sqrt{5^2 + 1^2}} = \frac{25 + 1}{26} = \mathbf{1.00}$$
- User C ভেক্টর: $\mathbf{u}_C = [1, 5]$
  $$\text{Sim}(D, C) = \frac{5(1) + 1(5)}{\sqrt{26} \sqrt{26}} = \frac{10}{26} \approx \mathbf{0.385}$$

#### ২. ওয়েটেড প্রেডিকশন সূত্র:
$$\hat{r}_{u, i} = \frac{\sum_{v \in \text{Neighbors}} \text{Sim}(u, v) \cdot r_{v, i}}{\sum_{v \in \text{Neighbors}} |\text{Sim}(u, v)|}$$
নিকটবর্তী প্রতিবেশী হিসেবে User A ($Sim = 1.0$) ও User C ($Sim = 0.385$) কে নিলে:
$$\hat{r}_{D, 2} = \frac{1.00 \times 4 + 0.385 \times 1}{1.00 + 0.385} = \frac{4.0 + 0.385}{1.385} = \frac{4.385}{1.385} \approx \mathbf{3.17}$$
- যদি কেবল টপ-১ নেইবার (User A) নেওয়া হয়, তবে প্রেডিকশন হবে: **৪.০**! সুতরাং ইউজার D-কে মুভি ২ রেকমেন্ড করা অত্যন্ত যুক্তিযুক্ত।

---

### ৪.৩ ম্যাট্রিক্স ফ্যাক্টরাইজেশন (Matrix Factorization) ও ALS
ম্যাট্রিক্স ফ্যাক্টরাইজেশন রেটিং ম্যাট্রিক্স $R \in \mathbb{R}^{m \times n}$-কে দুটি লো-র‍্যাঙ্ক ম্যাট্রিক্সে ভাঙে: $R \approx U V^\top$, যেখানে ইউজার ভেক্টর $\mathbf{u}_i \in \mathbb{R}^k$ এবং আইটেম ভেক্টর $\mathbf{v}_j \in \mathbb{R}^k$ ($k \ll \min(m, n)$)।

#### Alternating Least Squares (ALS) অপটিমাইজেশন:
লস ফাংশনে $U$ ও $V$ উভয়ই ভ্যারিয়েবল হওয়ায় সমস্যাটি নন-কনভেক্স (Non-Convex)। ALS একবার $V$-কে স্থির রেখে $U$-এর গাণিতিক ক্লোজড-ফর্ম সমাধান করে, তারপর $U$-কে স্থির রেখে $V$-এর সমাধান করে:
$$\mathbf{u}_i = \left( V^\top V + \lambda I \right)^{-1} V^\top \mathbf{r}_i$$
$$\mathbf{v}_j = \left( U^\top U + \lambda I \right)^{-1} U^\top \mathbf{r}_j$$
- প্রতিটি স্টেপ সম্পূর্ণ কনভেক্স এবং স্বাধীন, ফলে Spark বা GPU ক্লাস্টারে লক্ষ লক্ষ ইউজারের জন্য প্যারালালে দ্রুত ট্রেইনিং করা যায়।

#### ইমপ্লিসিট ফিডব্যাকের জন্য BPR Loss (Rendle et al., UAI 2009):
ক্লিক বা ভিউ ডেটাতে নেগেটিভ ফিডব্যাক থাকে না। Bayesian Personalized Ranking একটি পেয়ারওয়াইজ লস ব্যবহার করে: ইউজার $u$ যে আইটেম $i$ ইন্টারঅ্যাক্ট করেছে তার প্রেফারেন্স অজানা আইটেম $j$-এর চেয়ে বেশি হতে হবে:
$$\mathcal{L}_{\text{BPR}} = \sum_{(u, i, j) \in D_S} \ln \sigma(\hat{x}_{ui} - \hat{x}_{uj}) - \lambda_\Theta \|\Theta\|^2$$
যেখানে $\hat{x}_{ui} = \mathbf{u}_u^\top \mathbf{v}_i$।

### ৪.৪ আধুনিক টু-টাওয়ার আর্কিটেকচার (Two-Tower Retrieval Model)
ইন্ডাস্ট্রিতে কোটি কোটি আইটেম থেকে ৫ মিলি-সেকেন্ডের মধ্যে ক্যান্ডিডেট বের করতে **Two-Tower Neural Network** ব্যবহার করা হয় (YouTube, Google Play, Pinterest):

```
User Context Features                            Item Metadata Features
(User ID, Search History, Age, Country)         (Item ID, Title, Category, Tags)
              │                                                │
              ▼                                                ▼
       ┌──────────────┐                                 ┌──────────────┐
       │  USER TOWER  │                                 │  ITEM TOWER  │
       │ (Deep MLP)   │                                 │ (Deep MLP)   │
       └──────────────┘                                 └──────────────┘
              │                                                │
              ▼                                                ▼
    User Embedding: u(x) ∈ R^d                       Item Embedding: v(y) ∈ R^d
              │                                                │
              └───────────────────┬────────────────────────────┘
                                  ▼
                         Dot Product / Cosine
                       Score = ⟨u(x), v(y)⟩
                                  │
                                  ▼
                    Vector Database (ScaNN / FAISS)
                   Sub-millisecond MIPS Retrieval
```

- **সার্ভিং স্পিড ট্রিক:** আইটেম কোটি কোটি হলেও তাদের এমবেডিং $\mathbf{v}(y)$ অফলাইনে আগে থেকেই হিসাব করে **FAISS** বা **ScaNN** ভেক্টর ডাটাবেসে ইনডেক্স করে রাখা হয়। অনলাইন রিকোয়েস্টে শুধু ইউজার এমবেডিং $\mathbf{u}(x)$ বের করে ডট-প্রোডাক্ট সার্চ করলেই কয়েক মিলি-সেকেন্ডে সেরা ক্যান্ডিডেট চলে আসে।

### ৪.৫ কোল্ড-স্টার্ট সমস্যা ও মাল্টি-আর্মড ব্যান্ডিট সমাধান
1. **নতুন ইউজার:** অতীত কোনো হিস্ট্রি নেই। সমাধান: অনবোর্ডিং প্রশ্নমালা, পপুলার আইটেম প্রদর্শন, এবং জিওগ্রাফিক/ডিভাইস মেটাডেটা ব্যবহার।
2. **নতুন আইটেম:** কেউ দেখেনি বলে কোলাবোরেটিভ ফিল্টারিং একে কখনো রেকমেন্ড করতে পারবে না। সমাধান: কনটেন্ট এমবেডিং এবং **Explore-Exploit (Multi-Armed Bandits)**:
   - **Upper Confidence Bound (UCB):** $\text{Score}_i = \hat{\mu}_i + c \sqrt{\frac{\ln N}{n_i}}$
   - আনসার্টেইনটি বা অনিশ্চয়তা বেশি হলে ($n_i$ ছোট) মডেল আইটেমটিকে এক্সপ্লোর করার জন্য বেশি সুযোগ দেয়।

### ৪.৬ রেকমেন্ডেশন সিস্টেমের মূল্যায়ন মেট্রিক্স (Evaluation Metrics)

#### Normalized Discounted Cumulative Gain (NDCG@K) গাণিতিক সূত্র:
$$\text{DCG}@K = \sum_{i=1}^K \frac{2^{rel_i} - 1}{\log_2(i + 1)}, \quad \text{NDCG}@K = \frac{\text{DCG}@K}{\text{IDCG}@K}$$
যেখানে $rel_i$ = ইউজারের কাছে আইটেমটির প্রাসঙ্গিকতা (Relevance), এবং $\text{IDCG}$ = আদর্শ (Ideal) পারফেক্ট র‍্যাঙ্কিংয়ের DCG।

#### 🔢 হাতে-কলমে NDCG@3 হিসাব:
ধরি ইউজারকে ৩টি আইটেম রেকমেন্ড করা হয়েছে যার প্রকৃত রেলেভ্যান্স: $[rel_1 = 3, rel_2 = 0, rel_3 = 2]$।
- **মডেলের DCG@3:**
  $$\text{DCG}@3 = \frac{2^3 - 1}{\log_2(1 + 1)} + \frac{2^0 - 1}{\log_2(2 + 1)} + \frac{2^2 - 1}{\log_2(3 + 1)}$$
  $$\text{DCG}@3 = \frac{7}{\log_2(2)} + \frac{0}{\log_2(3)} + \frac{3}{\log_2(4)} = \frac{7}{1} + 0 + \frac{3}{2} = 7 + 1.5 = \mathbf{8.5}$$
- **আদর্শ (Ideal) র‍্যাঙ্কিং:** রেলেভ্যান্স বড় থেকে ছোট সাজালে হবে: $[3, 2, 0]$।
  $$\text{IDCG}@3 = \frac{2^3 - 1}{\log_2(2)} + \frac{2^2 - 1}{\log_2(3)} + \frac{2^0 - 1}{\log_2(4)} = \frac{7}{1} + \frac{3}{1.585} + 0 \approx 7 + 1.893 = \mathbf{8.893}$$
- **ফাইনাল NDCG@3:**
  $$\text{NDCG}@3 = \frac{8.5}{8.893} \approx \mathbf{0.9558} \quad (\mathbf{95.6\%})$$

### ৫.১ টাইম-সিরিজ ফিচার আর্কিটেকচার ও ফিউচার লিকেজ প্রতিরোধ
মডেলকে টাইম-সিরিজ শেখাতে হলে ল্যাগ ফিচার (Lag Features) ও রোলিং স্ট্যাট ব্যবহার করতে হয়:
- **ল্যাগ ফিচার:** $x_{t-1}, x_{t-2}, x_{t-7}, x_{t-14}$ (দৈনিক ও সাপ্তাহিক প্যাটার্ন)।
- **রোলিং স্ট্যাটিস্টিকস:** গত ৭ দিনের গড় $\mu_{t-1, 7}$ এবং ভ্যারিয়্যান্স $\sigma_{t-1, 7}^2$।
- **মারাত্মক ফিউচার লিকেজ (Future Information Leakage):** ভুলবশত যদি বর্তমান সময়ের মান সহ রোলিং উইন্ডো হিসাব করা হয় ($\mu_{t, 7}$), তবে মডেল ট্রেইনিংয়ে ৯৯% এক্যুরেসি দেখাবে কিন্তু লাইভ প্রোডাকশনে ক্র্যাশ করবে! তাই কঠোরভাবে নিশ্চিত করতে হবে: $\text{Feature}_t = f(\{x_{t-1}, x_{t-2}, \dots\})$।

### ৫.২ অ্যানোম্যালি স্কোরিং টেকনিক্স
1. **Mahalanobis Distance (মাল্টিভ্যারিয়েট ডিস্ট্রিবিউশন):**
   $$D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$$
   ফিচারসমূহের মধ্যকার কোভ্যারিয়্যান্স ম্যাট্রিক্স $\boldsymbol{\Sigma}$ বিবেচনায় নিয়ে মাল্টি-ডাইমেনশনাল স্পেসে আউটলায়ার দূরত্ব মাপে।
2. **অটোএনকোডার রিকনস্ট্রাকশন এরর (Autoencoder Anomaly Detection):**
   একটি ডিপ অটোএনকোডারকে কেবল নরমাল (অ্যানোম্যালিবিহীন) ডেটার ওপর ট্রেন করা হয়।
   - নরমাল ইনপুট আসলে সে নিখুঁতভাবে রিকনস্ট্রাক্ট করতে পারে ($L \approx 0$)।
   - হঠাৎ অস্বাভাবিক অ্যানোম্যালি প্যাটার্ন আসলে মডেল তা রিকনস্ট্রাক্ট করতে ব্যর্থ হয়:
     $$\text{Anomaly Score} = \|\mathbf{x} - \hat{\mathbf{x}}\|_2^2 = \sum_{j=1}^D (x_j - \hat{x}_j)^2 > \tau$$

### ৫.৩ চেঞ্জ-পয়েন্ট ডিটেকশন (CUSUM অ্যালগরিদম)
Cumulative Sum (CUSUM) অ্যালগরিদম টাইম-সিরিজের গড়ে হঠাৎ কাঠামোগত স্থানান্তর শনাক্ত করে:
$$S_t^+ = \max(0, S_{t-1}^+ + (x_t - \mu_0 - k))$$
$$S_t^- = \max(0, S_{t-1}^- - (x_t - \mu_0 + k))$$
যখন $S_t^+$ বা $S_t^-$ নির্ধারিত থ্রেশহোল্ড $h$ অতিক্রম করে, তখনই সিস্টেম তাত্ক্ষণিক চেঞ্জ-পয়েন্ট অ্যালার্ম ট্রিগার করে।

# ৭. প্রোডাকশন-গ্রেড পাইথন ইমপ্লিমেন্টেশন কোড

### ৭.১ কম্পিউটার ভিশন: বাউন্ডিং বক্স IoU ও Non-Maximum Suppression (NMS)

```python
    দুটি বাউন্ডিং বক্সের Intersection over Union (IoU) গণনা করে।

    """
    # ইন্টারসেকশন কোঅর্ডিনেট
    x_left = max(box_a[0], box_b[0])
    y_top = max(box_a[1], box_b[1])
    x_right = min(box_a[2], box_b[2])
    y_bottom = min(box_a[3], box_b[3])

    if x_right < x_left or y_bottom < y_top:
        return 0.0

    intersection_area = (x_right - x_left) * (y_bottom - y_top)

    area_a = (box_a[2] - box_a[0]) * (box_a[3] - box_a[1])
    area_b = (box_b[2] - box_b[0]) * (box_b[3] - box_b[1])

    union_area = float(area_a + area_b - intersection_area)
    return intersection_area / union_area if union_area > 0 else 0.0

def non_maximum_suppression(boxes: np.ndarray, scores: np.ndarray, iou_threshold: float = 0.5):
    """
    Non-Maximum Suppression (NMS) অ্যালগরিদম।
    boxes: শেইপ [N, 4]
    scores: শেইপ [N]
    """
    if len(boxes) == 0:
        return []

    picked_indices = []
    order = scores.argsort()[::-1] # কনফিডেন্স অনুযায়ী ডিসেন্ডিং অর্ডার

    while order.size > 0:
        best_idx = order[0]
        picked_indices.append(best_idx)

        # সেরা বক্সের সাথে বাকিদের IoU বের করা
        ious = np.array([compute_iou(boxes[best_idx], boxes[i]) for i in order[1:]])

        # IoU থ্রেশহোল্ডের নিচে থাকা বক্সগুলো রেখে বাকিগুলো ড্রপ করা
        surviving = np.where(ious <= iou_threshold)[0]
        order = order[surviving + 1]

    return picked_indices

if __name__ == "__main__":
    # ডেমো বক্স ও কনফিডেন্স স্কোর
    test_boxes = np.array([
        [20, 20, 80, 80],   # Box 1 (Ground Truth এর কাছাকাছি)
        [22, 21, 79, 81],   # Box 2 (Box 1 এর খুব কাছাকাছি ডুপ্লিকেট)
        [150, 150, 200, 200] # Box 3 (ভিন্ন অবজেক্ট)
    ])
    test_scores = np.array([0.92, 0.85, 0.78])

    selected = non_maximum_suppression(test_boxes, test_scores, iou_threshold=0.5)
    print("NMS দ্বারা নির্বাচিত বক্স ইনডেক্স:", selected)
    print("নির্বাচিত বক্সসমূহ:\n", test_boxes[selected])
```

### ৭.২ রেকমেন্ডেশন সিস্টেম: টু-টাওয়ার (Two-Tower) রিট্রিভাল নেটওয়ার্ক (PyTorch)

```python
"""
two_tower_recsys.py
Dual-Tower Candidate Retrieval Neural Network in PyTorch
"""
import torch
import torch.nn as nn
import torch.nn.functional as F

class UserTower(nn.Module):
    def __init__(self, num_users: int, embedding_dim: int, output_dim: int):
        super().__init__()
        self.user_emb = nn.Embedding(num_users, embedding_dim)
        self.mlp = nn.Sequential(
            nn.Linear(embedding_dim, 64),
            nn.ReLU(),
            nn.Linear(64, output_dim)
        )

    def forward(self, user_ids):
        x = self.user_emb(user_ids)
        x = self.mlp(x)
        return F.normalize(x, p=2, dim=-1) # L2 Normalization

class ItemTower(nn.Module):
    def __init__(self, num_items: int, embedding_dim: int, output_dim: int):
        super().__init__()
        self.item_emb = nn.Embedding(num_items, embedding_dim)
        self.mlp = nn.Sequential(
            nn.Linear(embedding_dim, 64),
            nn.ReLU(),
            nn.Linear(64, output_dim)
        )

    def forward(self, item_ids):
        x = self.item_emb(item_ids)
        x = self.mlp(x)
        return F.normalize(x, p=2, dim=-1) # L2 Normalization

class TwoTowerModel(nn.Module):
    def __init__(self, num_users, num_items, embedding_dim=32, output_dim=16):
        super().__init__()
        self.user_tower = UserTower(num_users, embedding_dim, output_dim)
        self.item_tower = ItemTower(num_items, embedding_dim, output_dim)
        self.temperature = nn.Parameter(torch.ones(1) * 0.07)

    def forward(self, user_ids, item_ids):
        user_vectors = self.user_tower(user_ids) # [B, output_dim]
        item_vectors = self.item_tower(item_ids) # [B, output_dim]
        
        # ব্যাচের ভেতরের সমস্ত ইউজার ও আইটেমের ডট প্রোডাক্ট সিমিলারিটি
        logits = torch.matmul(user_vectors, item_vectors.T) / self.temperature
        return logits

if __name__ == "__main__":
    torch.manual_seed(42)
    model = TwoTowerModel(num_users=1000, num_items=500, embedding_dim=16, output_dim=8)
    
    # ডেমো ব্যাচ (৪ জন ইউজার ও তাদের পজিটিভ আইটেম ইন্টারঅ্যাকশন)
    users = torch.tensor([1, 5, 23, 89])
    pos_items = torch.tensor([10, 42, 105, 301])
    
    sim_logits = model(users, pos_items)
    print("সিমিলারিটি ম্যাট্রিক্স শেইপ:", sim_logits.shape)
    print("ডায়াগোনাল স্কোর (পজিটিভ পেয়ারস):\n", torch.diag(sim_logits).detach().numpy())
```
