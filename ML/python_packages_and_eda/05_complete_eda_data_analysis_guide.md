## ২. পরিসংখ্যানিক ভিত্তি ও হাতে-কলমে গাণিতিক হিসাব

### ২.১ স্কিউনেস (Skewness: Fisher-Pearson 3rd Standardized Moment)

#### সূত্র (Formula):
$$g_1 = \frac{m_3}{m_2^{3/2}} = \frac{\frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^3}{\left(\frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2\right)^{3/2}}$$

#### বাস্তব ডেমো ডেটাসেট ($n = 5$):
ধরা যাক ৫ জন গ্রাহকের অ্যাকাউন্টে জমার পরিমাণ (হাজার টাকায়):
$$X = [2, 3, 3, 4, 18]$$

#### স্টেপ-বাই-স্টেপ ক্যালকুলেশন:
1. **গড় (Mean, $\bar{x}$):**
   $$\bar{x} = \frac{2 + 3 + 3 + 4 + 18}{5} = \frac{30}{5} = 6.0$$

2. **বিচ্যুতি (Deviations, $x_i - \bar{x}$):**
   - $2 - 6 = -4$
   - $3 - 6 = -3$
   - $3 - 6 = -3$
   - $4 - 6 = -2$
   - $18 - 6 = +12$

3. **২য় কেন্দ্রীয় মোমেন্ট ($m_2$, ভ্যারিয়েন্স):**
   $$\sum (x_i - \bar{x})^2 = (-4)^2 + (-3)^2 + (-3)^2 + (-2)^2 + (12)^2 = 16 + 9 + 9 + 4 + 144 = 182$$
   $$m_2 = \frac{182}{5} = 36.4$$
   $$m_2^{3/2} = (36.4)^{1.5} \approx 219.613$$

4. **৩য় কেন্দ্রীয় মোমেন্ট ($m_3$, কিউবিক বিচ্যুতি):**
   $$\sum (x_i - \bar{x})^3 = (-4)^3 + (-3)^3 + (-3)^3 + (-2)^3 + (12)^3 = -64 - 27 - 27 - 8 + 1728 = +1602$$
   $$m_3 = \frac{1602}{5} = 320.4$$

5. **স্কিউনেস ($g_1$):**
   $$g_1 = \frac{320.4}{219.613} = \mathbf{+1.459}$$

- **ব্যাখ্যা:** $g_1 > +1.0$ হওয়ায় এটি **প্রচণ্ড রাইট-স্কিউড (Right-skewed / Positive Skew)**। অর্থাৎ ডানদিকে একটি বিশাল লেজ বা আউটলায়ার ($18$) রয়েছে।
- **কেন ব্যবহার করবেন:** লিনিয়ার রিগ্রেশন বা নিউরাল নেটওয়ার্কে স্কিউড ফিচার সরাসরি দিলে মডেল বড় সংখ্যার প্রতি বায়াসড হয়ে পড়ে।
- **কখন ব্যবহার করবেন না:** বাইমডাল (Bimodal - দুটি চূড়াযুক্ত) ডেটায় স্কিউনেস ০ দেখালেও ডেটা মোটেও স্বাভাবিক নয়। সেখানে হিস্টোগ্রাম ছাড়া বোঝা অসম্ভব।
- **প্রতিকার:** $\log(1 + x)$ বা Box-Cox / Yeo-Johnson পাওয়ার ট্রান্সফর্মেশন।

---

### ২.২ কার্টোসিস (Excess Kurtosis: Tail Weight & Outlier Proneness)

#### সূত্র (Formula):
$$g_2 = \frac{m_4}{m_2^2} - 3 = \frac{\frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^4}{\left(\frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2\right)^2} - 3$$
*(স্বাভাবিক বা নরমাল ডিস্ট্রিবিউশনের কার্টোসিস ৩, তাই অতিরিক্ত টেল-ওয়েট বুঝতে ৩ বিয়োগ করা হয়।)*

#### স্টেপ-বাই-স্টেপ ক্যালকুলেশন (একই ডেটাসেট $X = [2, 3, 3, 4, 18]$):
1. **৪র্থ পাওয়ার বিচ্যুতি $\sum (x_i - \bar{x})^4$:**
   $$\sum (x_i - \bar{x})^4 = (-4)^4 + (-3)^4 + (-3)^4 + (-2)^4 + (12)^4$$
   $$= 256 + 81 + 81 + 16 + 20736 = 21170$$
   $$m_4 = \frac{21170}{5} = 4234.0$$

2. **$m_2^2$ নির্ণয়:**
   $$m_2^2 = (36.4)^2 = 1324.96$$

3. **Excess Kurtosis ($g_2$):**
   $$g_2 = \frac{4234.0}{1324.96} - 3 = 3.1956 - 3 = \mathbf{+0.1956}$$

- **ব্যাখ্যা:** $g_2 > 0$ হওয়ায় এটি **Leptokurtic (Fat-tailed)**। এর অর্থ ডেটাতে চরম আউটলায়ার থাকার সম্ভাবনা বেশি। যদি $g_2 < 0$ হতো, তবে তা হতো Platykurtic (পাতলা লেজ, কম আউটলায়ার)।

### ২.৩ পিয়ারসন কোরিলেশন কোএফিশিয়েন্ট ($r$: Linear Association)

#### সূত্র:
$$r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}}$$

#### বাস্তব ডেটাসেট ($n=5$):
- $X$ = পড়াশোনার ঘণ্টা: $[1, 2, 3, 4, 5]$ ($\bar{x} = 3.0$)
- $Y$ = পরীক্ষার নম্বর: $[2, 3, 5, 7, 11]$ ($\bar{y} = \frac{28}{5} = 5.6$)

#### টেবুলার ক্যালকুলেশন:

| $i$ | $x_i$ | $y_i$ | $x_i - \bar{x}$ | $y_i - \bar{y}$ | $(x_i - \bar{x})^2$ | $(y_i - \bar{y})^2$ | $(x_i - \bar{x})(y_i - \bar{y})$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 1 | 1 | 2 | $-2$ | $-3.6$ | 4 | 12.96 | $+7.2$ |
| 2 | 2 | 3 | $-1$ | $-2.6$ | 1 | 6.76 | $+2.6$ |
| 3 | 3 | 5 | $0$ | $-0.6$ | 0 | 0.36 | $0.0$ |
| 4 | 4 | 7 | $+1$ | $+1.4$ | 1 | 1.96 | $+1.4$ |
| 5 | 5 | 11 | $+2$ | $+5.4$ | 4 | 29.16 | $+10.8$ |
| **মোট**| | | | | **10** | **51.20** | **+22.0** |

#### চূড়ান্ত মান:
$$r = \frac{22.0}{\sqrt{10 \times 51.20}} = \frac{22.0}{\sqrt{512}} = \frac{22.0}{22.627} = \mathbf{+0.9723}$$

- **সিদ্ধান্ত:** পড়াশোনার ঘণ্টার সাথে নম্বরের **+০.৯৭২৪ শক্তিশালী ধনাত্মক রৈখিক সম্পর্ক (Strong Positive Linear Correlation)** বিদ্যমান।
- **কোথায় ব্যবহার করবেন না:** নন-লিনিয়ার বা এক্সপোনেনশিয়াল সম্পর্কে পিয়ারসন বিভ্রান্তিকর ফলাফল দেয় (যেমন: Anscombe's Quartet)।

### ২.৪ স্পিয়ারম্যান র‍্যাংক কোরিলেশন ($\rho$: Monotonic Association)

#### সূত্র:
$$\rho = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}$$
যেখানে $d_i = \text{Rank}(x_i) - \text{Rank}(y_i)$।

#### বাস্তব ডেটাসেট ($n=5$):
- $X = [1, 2, 3, 4, 5]$
- $Y = [1, 10, 100, 1000, 10000]$ (সম্পূর্ণ নন-লিনিয়ার এক্সপোনেনশিয়াল বৃদ্ধি!)

#### র‍্যাংক ও পার্থক্য:
- $\text{Rank}(X) = [1, 2, 3, 4, 5]$
- $\text{Rank}(Y) = [1, 2, 3, 4, 5]$
- $d = [0, 0, 0, 0, 0] \implies \sum d_i^2 = 0$

$$\rho = 1 - \frac{6 \times 0}{5(25 - 1)} = \mathbf{1.0}$$

- **পার্থক্য লক্ষ্য করুন:** এই ডেটাতে পিয়ারসন $r \approx 0.74$ দেবে (নন-লিনিয়ার বলে দুর্বল দেখাবে), কিন্তু স্পিয়ারম্যান সঠিকভাবে $\mathbf{1.0}$ দেবে কারণ সম্পর্কটি নিখুঁত মনোটনিক (একটি বাড়লে অপরটি সর্বদা বাড়ে)।

### ২.৫ কাই-স্কয়ার টেস্ট অব ইন্ডিপেন্ডেন্স ($\chi^2$: Categorical Association)

#### সূত্র:
$$\chi^2 = \sum \frac{(O - E)^2}{E}$$
যেখানে $O$ = Observed Frequency এবং $E = \frac{\text{Row Total} \times \text{Col Total}}{\text{Grand Total}}$।

#### কন্টিঞ্জেন্সি টেবিল ($N = 1000$ গ্রাহক):
সাবস্ক্রিপশনের ধরনের সাথে গ্রাহক ড্রপ বা চার্ন (Churn) হওয়ার সম্পর্ক যাচাই:

| সাবস্ক্রিপশন ধরণ | চার্ন করেছে (Churned = 1) | চার্ন করেনি (Retained = 0) | সারি মোট (Row Total) |
| :--- | :---: | :---: | :---: |
| **মাসিক চুক্তি (Monthly)** | $O_{11} = 200$ | $O_{12} = 300$ | **500** |
| **বার্ষিক চুক্তি (Annual)** | $O_{21} = 50$ | $O_{22} = 450$ | **500** |
| **কলাম মোট (Col Total)** | **250** | **750** | **Grand Total = 1000** |

#### প্রত্যাশিত মান ($E$) গণনা:
- $E_{11} = \frac{500 \times 250}{1000} = 125.0$
- $E_{12} = \frac{500 \times 750}{1000} = 375.0$
- $E_{21} = \frac{500 \times 250}{1000} = 125.0$
- $E_{22} = \frac{500 \times 750}{1000} = 375.0$

#### $\frac{(O - E)^2}{E}$ এর সেলভিত্তিক গণনা:
1. সেল (Monthly, Churned): $\frac{(200 - 125)^2}{125} = \frac{75^2}{125} = \frac{5625}{125} = 45.0$
2. সেল (Monthly, Retained): $\frac{(300 - 375)^2}{375} = \frac{(-75)^2}{375} = \frac{5625}{375} = 15.0$
3. সেল (Annual, Churned): $\frac{(50 - 125)^2}{125} = \frac{(-75)^2}{125} = \frac{5625}{125} = 45.0$
4. সেল (Annual, Retained): $\frac{(450 - 375)^2}{375} = \frac{75^2}{375} = \frac{5625}{375} = 15.0$

$$\chi^2 = 45.0 + 15.0 + 45.0 + 15.0 = \mathbf{120.0}$$

- **ডিগ্রিজ অব ফ্রিডম ($df$):**
  $$df = (\text{Rows} - 1) \times (\text{Cols} - 1) = (2 - 1) \times (2 - 1) = 1$$
- **সিদ্ধান্ত:** $df = 1$ এর জন্য ৯৯.৯% কনফিডেন্স লেভেলে ক্রিটিক্যাল ভ্যালু হলো $10.83$। যেহেতু আমাদের প্রাপ্ত $\chi^2 = 120.0 \gg 10.83$, তাই নাল হাইপোথিসিস বাতিল! চুক্তির ধরনের সাথে গ্রাহক চার্নের অত্যন্ত শক্তিশালী পরিসংখ্যানিক নির্ভরতা রয়েছে।

### ২.৬ মাল্টিকোলিনিয়ারিটি ও Variance Inflation Factor (VIF)

লিনিয়ার মডেলে দুটি ফিচার একে অপরের প্রায় প্রতিরূপ হলে কোএফিশিয়েন্টের ভ্যারিয়েন্স বিস্ফোরিত হয়:
$$\text{Var}(\hat{\beta}_j) = \frac{\sigma^2}{\sum (x_{ij} - \bar{x}_j)^2} \cdot VIF_j$$

#### সূত্র:
$$VIF_j = \frac{1}{1 - R_j^2}$$
যেখানে $R_j^2$ হলো $X_j$ ফিচারকে টার্গেট ধরে বাকি সব ফিচারের ওপর চালানো ওএলএস (OLS) রিগ্রেশনের ডিটারমিনেশন কোএফিশিয়েন্ট।

#### সংখ্যা দিয়ে হিসাব:
ধরা যাক আমাদের কাছে দুটি ফিচার আছে: $X_1 = \text{Annual Salary}$ এবং $X_2 = \text{Monthly Income}$।
যদি $X_1$ কে $X_2$ দিয়ে প্রেডিক্ট করলে $R_1^2 = 0.96$ পাওয়া যায়:
$$VIF_1 = \frac{1}{1 - 0.96} = \frac{1}{0.04} = \mathbf{25.0}$$

- **থ্রেশহোল্ড:**
  - $VIF = 1$: কোনো কোলিনিয়ারিটি নেই।
  - $VIF > 5$: মাঝারি কোলিনিয়ারিটি (সতর্কবার্তা)।
  - $VIF > 10$: মারাত্মক কোলিনিয়ারিটি! যেকোনো একটি ফিচার অবশ্যই ড্রপ করতে হবে।

### ২.৭ আউটলায়ার ডিটেকশন ও $1.5 \times IQR$ নিয়মের গাণিতিক প্রমাণ

জন টুকি (John Tukey) কেন ঠিক **$1.5 \times IQR$** নির্বাচন করেছিলেন?

#### গাণিতিক প্রমাণ (Normal Distribution Proof):
একটি আদর্শ স্বাভাবিক বিন্যাসে $X \sim \mathcal{N}(\mu, \sigma^2)$:
- প্রথম কোয়ার্টাইল ($Q_1$): $25\%$ ক্ষেত্রফল $\implies Q_1 = \mu - 0.67449\sigma$
- তৃতীয় কোয়ার্টাইল ($Q_3$): $75\%$ ক্ষেত্রফল $\implies Q_3 = \mu + 0.67449\sigma$
- ইন্টার-কোয়ার্টাইল রেঞ্জ ($IQR$):
  $$IQR = Q_3 - Q_1 = 2 \times 0.67449\sigma \approx 1.34898\sigma$$

এবার উপরের সীমা (Upper Fence) হিসাব করি:
$$\text{Upper Fence} = Q_3 + k \cdot IQR$$
যদি $k = 1.5$ বসানো হয়:
$$\text{Upper Fence} = (\mu + 0.6745\sigma) + 1.5 \times (1.3490\sigma) = \mu + 0.6745\sigma + 2.0235\sigma = \mathbf{\mu + 2.698\sigma}$$

একইভাবে লোয়ার ফেন্স $= \mathbf{\mu - 2.698\sigma}$।
স্বাভাবিক বিন্যাসে $\mu \pm 2.698\sigma$ সীমার মধ্যে মোট ডেটার **$99.3\%$** অবস্থান করে। অর্থাৎ সাধারণ অবস্থায় মাত্র **$0.7\%$** ডেটা আউটলায়ার হিসেবে চিহ্নিত হবে! এটি টাইপ-১ এরর (False Positive) এবং আউটলায়ার ধরার ক্ষমতার মধ্যে নিখুঁত ভারসাম্য তৈরি করে।

## ৩. মিসিং ডেটা মেকানিজম (MCAR, MAR, MNAR) ও হ্যান্ডলিং স্ট্র্যাটেজি

| **MNAR** | **Missing Not At Random:** মিসিং হওয়া সরাসরি সেই ভ্যালুর তীব্রতার ওপর নির্ভর করে। | যারা অতিরিক্ত ঋণগ্রস্ত বা দেউলিয়া, তারা আয়ের প্রশ্নপত্র এড়িয়ে যায়। | ড্রপ করলে মডেল ধ্বংস হবে! মিসিং ফ্ল্যাগ ফিচার (`is_income_missing = 1`) তৈরি করে ট্রি-মডেলকে প্যাটার্ন শিখতে দেওয়া উচিত। |

## ৪. ডেটা লিকেজ (Data Leakage) ও ট্রেনিং-সার্ভিং স্কিউ

### ৪.১ টার্গেট লিকেজ (Target Leakage):
ভবিষ্যতের এমন কোনো তথ্য ট্রেইনিং ফিচারে ঢুকে যাওয়া যা টেস্ট বা প্রোডাকশন টাইমে পাওয়া সম্ভব নয়।
- *উদাহরণ:* গ্রাহক ঋণ খেলাপ করবে কিনা প্রেডিক্ট করার ফাইলে `collection_agency_contacted = True` রাখা! রিকভারি এজেন্ট তো ঋণ খেলাপ হওয়ার পরেই যোগাযোগ করে।
- *ডিটেকশন:* কোনো ফিচারের সাথে টার্গেটের কোরিলেশন যদি $0.98$ বা অদ্ভুত রকমের বেশি আসে, সঙ্গে সঙ্গে টার্গেট লিকেজ সন্দেহ করুন।

### ৪.২ প্রি-প্রসেসিং লিকেজ (Train-Test Contamination):
ট্রেন-টেস্ট স্প্লিট করার আগেই পুরো ডেটাসেটের গড় বের করে স্কেলিং করা।
- *নিয়ম:* সর্বদা `fit()` করবেন কেবল `X_train`-এর ওপর, আর `transform()` করবেন `X_train` এবং `X_test` উভয়ের ওপর।

### ৪.৩ ট্রেনিং-সার্ভিং স্কিউ (Training-Serving Skew):
- **কোভ্যারিয়েট শিফট ($P(X)$ পরিবর্তন):** ইনপুট ফিচারের বিন্যাস বদলে গেছে (যেমন: মুদ্রাস্ফীতির কারণে প্রোডাক্টের গড় মূল্য ২০% বৃদ্ধি)।
- **কনসেপ্ট ড্রিফট ($P(Y|X)$ পরিবর্তন):** একই ইনপুটের প্রেক্ষিতে গ্রাহকের আচরণ বদলে গেছে (যেমন: করোনা মহামারীর কারণে একই ইনকামের মানুষ অনলাইনে কেনাকাটা দ্বিগুণ করেছে)।

## ৫. সম্পূর্ণ প্রোডাকশন-গ্রেড কোড পাইপলাইন

```python
"""
production_eda_pipeline.py
Industrial-strength Exploratory Data Analysis & Quality Audit Pipeline
"""
import numpy as np
import pandas as pd
from scipy import stats
from statsmodels.stats.outliers_influence import variance_inflation_factor

class ComprehensiveEDAPipeline:
    def __init__(self, df: pd.DataFrame, target_col: str):
        self.df = df.copy()
        self.target_col = target_col
        self.findings = []
        self.numeric_cols = self.df.select_dtypes(include=[np.number]).columns.drop(target_col, errors='ignore')
        self.categorical_cols = self.df.select_dtypes(include=['object', 'category']).columns.drop(target_col, errors='ignore')

    def run_sanity_and_missingness(self):
        print("=== ১. প্রাথমিক স্বাস্থ্য ও মিসিং পরীক্ষা ===")
        total_rows = len(self.df)
        dups = self.df.duplicated().sum()
        print(f"মোট সারি: {total_rows}, ডুপ্লিকেট: {dups} ({(dups/total_rows)*100:.2f}%)")
        
        missing_s = self.df.isna().sum()
        missing_pct = (missing_s / total_rows) * 100
        missing_report = pd.DataFrame({'Missing_Count': missing_s, 'Percent': missing_pct})
        missing_report = missing_report[missing_report['Missing_Count'] > 0].sort_values(by='Percent', ascending=False)
        print("মিসিং ভ্যালু সামারি:\n", missing_report)
        return missing_report

    def calculate_skew_and_kurtosis(self):
        print("\n=== ২. স্কিউনেস ও কার্টোসিস হিসাব ===")
        skew_kurt_df = pd.DataFrame(index=self.numeric_cols, columns=['Skewness', 'Kurtosis', 'Action'])
        for col in self.numeric_cols:
            clean_series = self.df[col].dropna()
            sk = stats.skew(clean_series)
            kt = stats.kurtosis(clean_series)
            
            action = "Normal"
            if sk > 1.0:
                action = "Log/Power Transform (Right-skew)"
            elif sk < -1.0:
                action = "Reflect & Log Transform (Left-skew)"
            
            skew_kurt_df.loc[col] = [round(sk, 3), round(kt, 3), action]
        print(skew_kurt_df)
        return skew_kurt_df

    def calculate_multicollinearity_vif(self):
        print("\n=== ৩. VIF ও মাল্টিকোলিনিয়ারিটি হিসাব ===")
        X_num = self.df[self.numeric_cols].dropna()
        vif_data = pd.DataFrame()
        vif_data["Feature"] = X_num.columns
        vif_data["VIF"] = [variance_inflation_factor(X_num.values, i) for i in range(X_num.shape[1])]
        vif_data = vif_data.sort_values(by="VIF", ascending=False).reset_index(drop=True)
        print(vif_data)
        return vif_data

    def detect_outliers_iqr(self):
        print("\n=== ৪. IQR আউটলায়ার স্ক্যান ===")
        outlier_summary = []
        for col in self.numeric_cols:
            q1 = self.df[col].quantile(0.25)
            q3 = self.df[col].quantile(0.75)
            iqr = q3 - q1
            lower = q1 - 1.5 * iqr
            upper = q3 + 1.5 * iqr
            outliers = self.df[(self.df[col] < lower) | (self.df[col] > upper)]
            outlier_summary.append({
                'Feature': col,
                'Lower_Fence': round(lower, 2),
                'Upper_Fence': round(upper, 2),
                'Outlier_Count': len(outliers),
                'Outlier_Pct': round(len(outliers) / len(self.df) * 100, 2)
            })
        print(pd.DataFrame(outlier_summary))
```
