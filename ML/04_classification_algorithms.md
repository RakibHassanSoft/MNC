## ১. লজিস্টিক রিগ্রেশন ও সফটম্যাক্স

### ১.১ সিগময়েড ফাংশন ও অডস রেশিও (Odds Ratio)
রৈখিক কম্বিনেশন $z = \mathbf{w}^T \mathbf{x} + b$ এর মান $-\infty$ থেকে $+\infty$ পর্যন্ত হতে পারে। এই মানকে $[0, 1]$ সম্ভাব্যতা স্পেসে রূপান্তর করতে লজিস্টিক সিগময়েড ব্যবহৃত হয়:
$$p = \sigma(z) = \frac{1}{1 + e^{-z}}$$

- **অডস রেশিও (Odds):** ঘটনার সম্ভাবনা বনাম না ঘটার সম্ভাবনার অনুপাত:
  $$\text{Odds} = \frac{p}{1 - p} = \frac{\frac{1}{1 + e^{-z}}}{1 - \frac{1}{1 + e^{-z}}} = \frac{\frac{1}{1 + e^{-z}}}{\frac{e^{-z}}{1 + e^{-z}}} = \frac{1}{e^{-z}} = e^z$$
- **লগ-অডস (Logit):** $\ln(\text{Odds}) = \ln(e^z) = \mathbf{z} = \mathbf{w}^T \mathbf{x} + b$। অর্থাৎ লজিস্টিক রিগ্রেশন আসলে লগ-অডসের ওপর একটি সরল লিনিয়ার মডেল!

---

### ১.২ ম্যাক্সিমাম লাইকলিহুড এস্টিমেশন (MLE) থেকে ক্রস-এনট্রপি লসের প্রতিপাদন
ধরি $y_i \in \{0, 1\}$। একটি একক স্যাম্পলের বার্নৌলি সম্ভাবনা:
$$P(y_i | \mathbf{x}_i) = p_i^{y_i} (1 - p_i)^{1 - y_i}$$

সকল স্বাধীন স্যাম্পলের যৌথ লাইকলিহুড ফাংশন:
$$L(\mathbf{w}) = \prod_{i=1}^m p_i^{y_i} (1 - p_i)^{1 - y_i}$$

লগ-লাইকলিহুড ($\ell(\mathbf{w})$) নিলে গুণফল যোগফলে রূপান্তরিত হয়:
$$\ell(\mathbf{w}) = \sum_{i=1}^m \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

মেশিন লার্নিংয়ে আমরা ম্যাক্সিমাইজ করার বদলে লসকে মিনিমাইজ করতে চাই, তাই ঋণাত্মক চিহ্ন যোগ করে পাই **বাইনারি ক্রস-এনট্রপি (Binary Cross-Entropy / Log Loss)**:
$$J(\mathbf{w}) = - \frac{1}{m} \sum_{i=1}^m \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

#### 🔢 হাতে-কলমে লজিস্টিক রিগ্রেশন প্রেডিকশন ও লস হিসাব:
ধরি একজন রোগীর টিউমার টেস্ট:
- মডেল প্যারামিটার: $w_1 = 0.8$ (Cell Size), $w_2 = 1.5$ (Thickness), বায়াস $b = -4.0$
- রোগীর ইনপুট: $x_1 = 3.0, x_2 = 2.0$, প্রকৃত লেবেল: $y = 1$ (ক্যান্সার)

1. **লিনিয়ার স্কোর ($z$):**
   $$z = (0.8 \times 3.0 + 1.5 \times 2.0) - 4.0 = (2.4 + 3.0) - 4.0 = 5.4 - 4.0 = \mathbf{1.40}$$
2. **সিগময়েড প্রবাবিলিটি ($p$):**
   $$p = \frac{1}{1 + e^{-1.40}} = \frac{1}{1 + 0.2466} = \frac{1}{1.2466} \approx \mathbf{0.8022} \text{ (৮০.২% নিশ্চিত ক্যান্সার)}$$
3. **ক্রস-এনট্রপি লস গণনা:**
   $$\mathcal{L} = - [1 \cdot \ln(0.8022) + 0] = - (-0.2204) = \mathbf{0.2204}$$
   *(যদি মডেল ভুল করে $p=0.10$ দিত, লস হতো $-\ln(0.10) = 2.302$, অর্থাৎ ১১ গুণ বেশি পেনাল্টি পেত!)*

## ২. ডিসিশন ট্রি ক্লাসিফায়ার

```
              [Root Node: Total 14 (9 Yes, 5 No)]
                            /        \  Feature: Outlook
                           /          \
     [Outlook = Sunny: 2Y, 3N]      [Outlook = Overcast: 4Y, 0N (Pure Leaf!)]
```

### ২.১ অশুদ্ধতা পরিমাপের মেট্রিক্স:
1. **শ্যানন এন্ট্রপি (Entropy):** $H(S) = - \sum_{k=1}^K p_k \log_2(p_k)$
2. **জিনি ইম্পিউরিটি (Gini Impurity):** $\text{Gini}(S) = 1 - \sum_{k=1}^K p_k^2$
3. **ইনফরমেশন গেইন (Information Gain):**
   $$\text{IG}(S, A) = H(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} H(S_v)$$

#### 🔢 হাতে-কলমে একটি স্প্লিটের ইনফরমেশন গেইন গণনা:
ধরি পেরেন্ট নোডে মোট ১০টি স্যাম্পল আছে: **৭টি পজিটিভ ($+$), ৩টি নেগেটিভ ($-$)**।
- পেরেন্ট এন্ট্রপি $H(S) = - [0.7 \log_2 0.7 + 0.3 \log_2 0.3] = \mathbf{0.8813 \text{ bits}}$

একটি ফিচার $A$ দিয়ে নোডটিকে দুটি ভাগে ভাগ করা হলো:
- **চাইল্ড ১ ($D_1$):** ৫টি স্যাম্পল (৪টি $+$, ১টি $-$) $\implies p_+ = 4/5 = 0.8, p_- = 1/5 = 0.2$
  $$H(D_1) = - [0.8 \log_2 0.8 + 0.2 \log_2 0.2] = - [0.8(-0.3219) + 0.2(-2.3219)] = 0.2575 + 0.4644 = \mathbf{0.7219}$$
- **চাইল্ড ২ ($D_2$):** ৫টি স্যাম্পল (৩টি $+$, ২টি $-$) $\implies p_+ = 3/5 = 0.6, p_- = 2/5 = 0.4$
  $$H(D_2) = - [0.6 \log_2 0.6 + 0.4 \log_2 0.4] = - [0.6(-0.7370) + 0.4(-1.3219)] = 0.4422 + 0.5288 = \mathbf{0.9710}$$

**স্প্লিট পরবর্তী ওজনযুক্ত এন্ট্রপি:**
$$H(S | A) = \frac{5}{10}(0.7219) + \frac{5}{10}(0.9710) = 0.3610 + 0.4855 = \mathbf{0.8465}$$

**ইনফরমেশন গেইন:**
$$\text{IG} = H(S) - H(S | A) = 0.8813 - 0.8465 = \mathbf{0.0348 \text{ bits}}$$
- **ডিসিশন:** যে ফিচারের ইনফরমেশন গেইন সর্বোচ্চ হবে, ডিসিশন ট্রি সেই ফিচারটি দিয়ে রুট নোড স্প্লিট করবে।

## ৩. সাপোর্ট ভেক্টর মেশিন (SVM)

```
                       Class +1
                          o     o
                             \  Hyperplane: w^T x + b = +1 (Upper Margin)
          - - - - - - - - - - \ - - - - - - - - - - -
                   Margin Width = 2 / ||w||  (Separating Plane: w^T x + b = 0)
          - - - - - - - - - - / - - - - - - - - - - -
                             /  Hyperplane: w^T x + b = -1 (Lower Margin)
                          x     x
                       Class -1
```

### ৩.১ মার্জিন প্রস্থের গাণিতিক প্রতিপাদন
দুটি প্যারালাল মার্জিন বাউন্ডারি:
$\mathbf{w}^T \mathbf{x}_+ + b = +1$ এবং $\mathbf{w}^T \mathbf{x}_- + b = -1$
উভয় সমীকরণ বিয়োগ করলে পাই:
$$\mathbf{w}^T (\mathbf{x}_+ - \mathbf{x}_-) = 2$$
মার্জিনের প্রস্থ হলো ইউনিট নরমাল ভেক্টর $\frac{\mathbf{w}}{\|\mathbf{w}\|}$-এর ওপর প্রজেকশন:
$$\text{Margin} = \frac{\mathbf{w}^T (\mathbf{x}_+ - \mathbf{x}_-)}{\|\mathbf{w}\|} = \mathbf{\frac{2}{\|\mathbf{w}\|}}$$
মার্জিন সর্বোচ্চ করতে হলে $\|\mathbf{w}\|$ সর্বনিম্ন করতে হবে $\implies \min \frac{1}{2}\|\mathbf{w}\|^2$।

### ৩.২ সফট মার্জিন ও স্ল্যাক ভ্যারিয়েবল ($\xi_i$)
নন-সেপারেবল ডেটায় ভুলের অনুমতি দিতে স্ল্যাক ভ্যারিয়েবল $\xi_i \ge 0$ যুক্ত করা হয়:
$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i=1}^m \xi_i \quad \text{subject to } y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i$$
- **$C$ বড় হলে:** হার্ড মার্জিন, আউটলায়ারের কোনো ভুল সহ্য করবে না (ওভারফিটিংয়ের ঝুঁকি)।
- **$C$ ছোট হলে:** সফট মার্জিন, চওড়া মার্জিনের জন্য কিছু ভুল ক্ষমা করবে (বেশি জেনারালাইজড)।

### ৩.৩ কার্নেল ট্রিক (The Kernel Trick)
উচ্চমাত্রিক স্পেসে ট্রান্সফর্ম না করেই দুটি ভেক্টরের ডট প্রোডাক্ট হিসাব করা:
$$K(\mathbf{x}, \mathbf{x}') = \phi(\mathbf{x})^T \phi(\mathbf{x}')$$
- **Radial Basis Function (RBF / Gaussian):**
  $$K(\mathbf{x}, \mathbf{x}') = \exp\left( -\gamma \|\mathbf{x} - \mathbf{x}'\|^2 \right)$$
  এটি ডেটাকে তাত্ত্বিকভাবে একটি **অসীম-মাত্রিক (Infinite-dimensional)** হিলবার্ট স্পেসে প্রক্ষেপণ করে জটিল নন-লিনিয়ার বাউন্ডারি তৈরি করে।

## ৪. কে-নিয়ারেস্ট নেইবার্স (k-NN)

- **মডেলের ধরন:** লেজি লার্নার (Lazy Learner / Instance-based)। কোনো ট্রেনিং ধাপ নেই, টেস্ট টাইমে দূরত্ব হিসাব করে।
- **দূরত্ব সূত্র (Minkowski):** $D(\mathbf{x}, \mathbf{x}') = \left( \sum_{j=1}^n |x_j - x_j'|^p \right)^{1/p}$ ($p=1$ ম্যানহাটন, $p=2$ ইউক্লিডিয়ান)।
- **কার্স অব ডাইমেনশনালিটি:** ফিচার সংখ্যা ৫০ বা ১০০ ছাড়ালে ইউক্লিডিয়ান দূরত্বের পার্থক্য অর্থহীন হয়ে পড়ে।

## ৫. নেইভ বেইজ ক্লাসিফায়ার

বেইজের সূত্র ও শর্তাধীন স্বাধীনতা:
$$P(y | \mathbf{x}) = \frac{P(y) \prod_{j=1}^n P(x_j | y)}{P(\mathbf{x})}$$

### ৫.১ ল্যাপ্লাস স্মুথিং (Zero-Frequency Problem সমাধান):
যদি কোনো শব্দ টেস্ট ডেটায় থাকে কিন্তু কোনো ক্লাসে আগে না এসে থাকে, তবে তার সম্ভাবনা হবে ০, যা পুরো গুণফলকে শূন্য করে ফেলবে।
$$P(x_j | y) = \frac{N_{x_j, y} + \alpha}{N_y + \alpha |V|} \quad (\text{ডিফল্ট } \alpha = 1)$$

## ৬. লিনিয়ার (LDA) বনাম কোয়াড্রেটিক (QDA) ডিসক্রিমিন্যান্ট অ্যানালাইসিস

বেইসিয়ান ডিসিশন থিওরি অনুযায়ী, ডেটা পয়েন্ট $\mathbf{x}$ সেই ক্লাস $k$-তে যাবে যার পোস্টেরিওর $P(Y=k|\mathbf{x})$ সর্বোচ্চ।
লগ-পোস্টেরিওর এক্সপ্যান্ড করলে ডিসক্রিমিন্যান্ট ফাংশন দাঁড়ায়:
$$\delta_k(\mathbf{x}) = -\frac{1}{2} \ln |\Sigma_k| - \frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_k)^T \Sigma_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k) + \ln \pi_k$$

```
   LDA: Equal Covariances (Σ_1 = Σ_2)           QDA: Unequal Covariances (Σ_1 != Σ_2)
   Linear Decision Boundary                     Quadratic (Curved) Decision Boundary
           \                                            (         )
     o   o  \   x   x                             o   o  (   x   x )
   o   o     \    x                                 o   (  x   x    )
```

1. **LDA (Linear Discriminant Analysis):**
   - **শর্ত:** সব ক্লাসের কোভ্যারিয়্যান্স ম্যাট্রিক্স সমান ($\Sigma_k = \Sigma$)।
   - **প্রমাণ:** ব্র্যাকেট ভাঙলে দ্বিঘাত পদ $-\frac{1}{2}\mathbf{x}^T \Sigma^{-1} \mathbf{x}$ প্রতিটি ক্লাসে সমান থাকায় কাটাকাটি চলে যায়! ফলে সমীকরণটি $\mathbf{x}$-এর সাপেক্ষে কঠোরভাবে **রৈখিক (Linear)** হয়:
     $$\delta_k(\mathbf{x}) = \mathbf{x}^T \Sigma^{-1}\boldsymbol{\mu}_k - \frac{1}{2}\boldsymbol{\mu}_k^T \Sigma^{-1}\boldsymbol{\mu}_k + \ln \pi_k$$
2. **QDA (Quadratic Discriminant Analysis):**
   - **শর্ত:** প্রতিটি ক্লাসের নিজস্ব কোভ্যারিয়্যান্স ম্যাট্রিক্স থাকে ($\Sigma_k \neq \Sigma_j$)।
   - ফলে দ্বিঘাত পদটি কাটাকাটি যায় না, এবং ডিসিশন বাউন্ডারি **প্যারাবলিক বা হাইপারবোলিক (Curved Quadratic)** রূপ ধারণ করে।

## ৭. মাল্টিক্লাস ও মাল্টিলেবেল ক্লাসিফিকেশন টেকনিকস

### ৭.১ One-vs-Rest (OvR) বনাম One-vs-One (OvO)
- **OvR (One-vs-All):** $K$ সংখ্যক ক্লাসের জন্য $K$ টি বাইনারি মডেল ট্রেন করা হয় (Class $k$ বনাম Rest)। যে মডেলের কনফিডেন্স স্কোর সর্বোচ্চ, সেই ক্লাস ফাইনাল হয়।
- **OvO:** প্রতি দুটি ক্লাসের জোড়ার জন্য আলাদা মডেল ট্রেন করা হয়। মোট মডেল সংখ্যা $\frac{K(K-1)}{2}$।

### ৭.২ মাল্টিলেবেল (Multilabel Classification):
একটি আর্টিকেলে একই সাথে 'Sports' এবং 'Politics' দুটি লেবেলই সত্য হতে পারে।
- **Binary Relevance:** প্রতিটি লেবেলের জন্য স্বাধীন বাইনারি ক্লাসিফায়ার (লেবেলের পারস্পরিক সম্পর্ক মিস করে)।
- **Classifier Chains:** প্রথম ক্লাসিফায়ারের প্রেডিকশনকে দ্বিতীয় ক্লাসিফায়ারের ইনপুট ফিচার হিসেবে পাস করা হয়।

## ৯. স্ক্র্যাচ পাইথন ও Scikit-Learn প্রোডাকশন কোড

```python
"""
production_classification_pipeline.py
Scratch Logistic Regression with Vectorized Gradient Descent
"""
import numpy as np

class ScratchLogisticRegression:
    def __init__(self, lr: float = 0.05, n_iters: int = 1000):
        self.lr = lr
        self.n_iters = n_iters
        self.w = None
        self.b = 0.0

    def _sigmoid(self, z):
        return 1.0 / (1.0 + np.exp(-np.clip(z, -250, 250)))

    def fit(self, X: np.ndarray, y: np.ndarray):
        m, n = X.shape
        self.w = np.zeros(n)
        self.b = 0.0

        for _ in range(self.n_iters):
            # ফরওয়ার্ড পাস
            z = X @ self.w + self.b
            p = self._sigmoid(z)

            # ব্যাকওয়ার্ড পাস (ভেক্টরাইজড গ্রেডিয়েন্ট)
            error = p - y
            dw = (1.0 / m) * (X.T @ error)
            db = (1.0 / m) * np.sum(error)

            # প্যারামিটার আপডেট
            self.w -= self.lr * dw
            self.b -= self.lr * db
        return self

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        return self._sigmoid(X @ self.w + self.b)

    def predict(self, X: np.ndarray, threshold: float = 0.5) -> np.ndarray:
        return (self.predict_proba(X) >= threshold).astype(int)

if __name__ == "__main__":
    X_toy = np.array([[1.0, 2.0], [2.0, 3.0], [3.0, 1.0], [5.0, 4.0], [6.0, 5.0]])
    y_toy = np.array([0, 0, 0, 1, 1])

    clf = ScratchLogisticRegression(lr=0.1, n_iters=500).fit(X_toy, y_toy)
    test_pt = np.array([[4.5, 4.0]])
    prob = clf.predict_proba(test_pt)[0]
    print(f"Test Point Predicted Class: {clf.predict(test_pt)[0]} (Probability = {prob:.4f})")
```
