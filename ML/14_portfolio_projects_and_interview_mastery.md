### প্রজেক্ট ১: ক্লাসিক্যাল এমএল (Customer Churn & Business Cost Optimization)
- **ব্যবসায়িক সমস্যা:** সাবস্ক্রিপশনভিত্তিক সার্ভিসের ১০,০০০ গ্রাহকের ডেটা থেকে কারা আগামী মাসে সার্ভিস ছেড়ে চলে যাবে (Churn) তা শনাক্ত করা।
- **ডাটা কোয়ালিটি অডিট:** মিসিং ভ্যালু প্যাটার্ন, স্কিউনেস ও আউটলায়ার ট্রিটমেন্ট, VIF (Variance Inflation Factor) দিয়ে মাল্টিকলিনিয়ারিটি দূরীকরণ।
- **ডেটা লিকেজ কঠোর প্রতিরোধ:** সমস্ত স্কেলার (`StandardScaler`), ইম্পিউটার (`SimpleImputer`) এবং এনকোডার (`TargetEncoder`) শুধুমাত্র ট্রেইনিং ফোল্ডে ফিট করা এবং টেস্ট ফোল্ডে শুধু ট্রান্সফর্ম করা (Scikit-Learn `Pipeline` ব্যবহার করে)।
- **মডেল তুলনা:** Baseline Logistic Regression বনাম Random Forest বনাম Tuned LightGBM/CatBoost।
- **বিজনেস কস্ট অপটিমাইজেশন:** ডিফল্ট 0.5 থ্রেশহোল্ড প্রত্যাখ্যান করে বিজনেস কস্ট ম্যাট্রিক্স ($FN = \$100$ হারানো গ্রাহক, $FP = \$20$ রিটেনশন কল খরচ) এর ভিত্তিতে অপটিমাল থ্রেশহোল্ড $\theta^* = 0.22$ নির্ধারণ।
- **গভীর ত্রুটি বিশ্লেষণ:** ফলস নেগেটিভ গ্রাহকদের বৈশিষ্ট্য পর্যালোচনা (দেখা গেল ১ বছরের কন্ট্রাক্ট থাকা গ্রাহকদের মডেল বেশি মিস করেছে)।

### প্রজেক্ট ২: ডিপ লার্নিং (Industrial Defect Image Classifier in PyTorch)
- **সমস্যা:** ম্যানুফ্যাকচারিং প্ল্যান্টের ৫,০০০ ছবির মধ্য থেকে ৫ ধরনের কাঠামোগত ত্রুটি (Crack, Dent, Scratch, Rust, Good) স্বয়ংক্রিয়ভাবে শনাক্ত করা।
- **আর্কিটেকচার:** ImageNet-এ প্রি-ট্রেইন করা ResNet-50 ব্যাকবোনের ওপর কাস্টম ক্লাসিফায়ার হেড যুক্ত করা।
- **PyTorch প্রফেশনাল ইঞ্জিনিয়ারিং:**
  - কাস্টম `Dataset` এবং `DataLoader` (`pin_memory=True`, `num_workers=4`)।
  - অটোমেটিক মিক্সড প্রিসিশন (`torch.cuda.amp.autocast` ও `GradScaler`) ব্যবহার করে মেমরি ৫০% সাশ্রয় ও দ্বিগুণ গতি।
  - গ্রেডিয়েন্ট ক্লিপিং (`clip_grad_norm_`) এবং আর্লি স্টপিং (Patience = 5)।
- **নিখুঁত রিপ্রোডিউসিবিলিটি:** সিড ফিক্সেশন (`torch.manual_seed(42)`, `cudnn.deterministic = True`) এবং সম্পূর্ণ মডেল ও অপটিমাইজার স্টেট চেকপয়েন্টিং (`.pt`)।
- **লার্নিং কার্ভ ডায়াগনস্টিকস:** ট্রেন ও ভ্যালিডেশন লস কার্ভ বিশ্লেষণ করে আন্ডারফিটিং ও ওভারফিটিংয়ের কারণ চিহ্নিত করা।

### প্রজেক্ট ৩: প্রোডাকশন এমএল ও এমএলঅপ্স (Dockerized FastAPI Fraud Service)

- **স্কিমা ভ্যালিডেশন:** Pydantic v2 ফিল্ড রুলস (`gt=0, le=100000`, `@field_validator`) দিয়ে ইনপুট স্যানিটাইজেশন।
- **লগিং ও ট্রেসিং:** প্রতিটি রিকোয়েস্টে `request_id` (UUID4) যুক্ত করে স্ট্রাকচার্ড JSON লগিং।
- **কন্টেইনারাইজেশন:** অপটিমাইজড মাল্টি-স্টেজ ডকারফাইল ও সিকিউর নন-রুট ইউজার (`mluser`)।
- **অটোমেটেড CI/CD:** GitHub Actions ওয়ার্কফ্লো দিয়ে প্রতি পুশে Flake8 লিন্টিং, Pytest টেস্ট রান, ডকার ইমেজ বিল্ড এবং সিকিউরিটি স্ক্যান।
- **মনিটরিং:** ইনকামিং ফিচার শিফট পরিমাপে **Population Stability Index (PSI)** অটোমেশন এবং প্রোমেথিউস মেট্রিক্স স্ক্র্যাপিং।

### প্রজেক্ট ৪: ডোমেইন স্পেশালাইজেশন (Enterprise Hybrid RAG System)
- **সমস্যা:** কোম্পানির অভ্যন্তরীণ টেকনিক্যাল ম্যানুয়াল ও পলিসি নথিপত্র থেকে সত্যনিষ্ঠ উত্তর তৈরির সিস্টেম।
- **আর্কিটেকচার:** 
  - **Hybrid Search:** স্পার্স BM25 (নির্দিষ্ট কি-ওয়ার্ড খোঁজা) এবং ডেন্স ভেক্টর (শব্দার্থ বোঝা) এর যুগপৎ ব্যবহার।
  - **Reciprocal Rank Fusion (RRF):** $k = 60$ স্কেল দিয়ে র‍্যাঙ্ক ফিউশন করে টপ-২০ ক্যান্ডিডেট নির্বাচন।
  - **Cross-Encoder Reranker:** BGE-Reranker দিয়ে টপ-৫ অতি-প্রাসঙ্গিক চাঙ্ক ফিল্টার করে এলএলএম-এ পাঠানো।
- **ফ্যাকচুয়াল গ্রাউন্ডিং:** প্রতিটি তথ্যের পাশে সুনির্দিষ্ট সোর্স সাইটেশন (`[1]`, `[2]`) যুক্ত করা।
- **RAGAS ইভালুয়েশন ও নেগেটিভ টেস্টিং:** Context Precision, Faithfulness (হ্যালুসিনেশনহীনতা ৯৬.৮%) এবং ডকুমেন্টে উত্তর না থাকা ১০০টি নেগেটিভ প্রশ্নে সফলভাবে "তথ্যে নেই" বলে রিজেক্ট করা।
- **ইন্টারেক্টিভ ডেমো:** Streamlit দিয়ে তৈরি লাইভ ওয়েব ইন্টারফেস।

- **License:** MIT License
- **Contact:** mle-team@company.com

### পিলার ২: গণিত, সম্ভাবনা ও পরিসংখ্যান

#### ❓ প্রশ্ন ২.১: "সেন্ট্রাল লিমিট থিওরেম (CLT) কী এবং এটি মেশিন লার্নিং ভ্যালিডেশনে কেন ভিত্তিপ্রস্তর?"
**উত্তর:**
যেকোনো অজানা বা নন-নরমাল ডিস্ট্রিবিউশন (যেমন: ইউনিফর্ম, এক্সপোনেনশিয়াল) থেকে যদি পর্যাপ্ত আকারের ($n \ge 30$) স্বাধীন ও অভিন্নভাবে বণ্টিত (i.i.d.) দৈব নমুনা (Sample) নিয়ে তাদের গড় ($\bar{X}$) হিসাব করা হয়, তবে নমুনার গড়ের ডিস্ট্রিবিউশনটি একটি নিখুঁত **নরমাল (গাউসিয়ান) ডিস্ট্রিবিউশন** ধারণ করবে:
$$\bar{X}_n \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$$
- **এমএলে গুরুত্ব:** এই কারণেই $K$-ফোল্ড ক্রস-ভ্যালিডেশনের গড় স্কোর ($\bar{s}$) এবং কনফিডেন্স ইন্টারভাল বের করতে আমরা স্ট্যান্ডার্ড এরর $\frac{\sigma}{\sqrt{K}}$ ব্যবহার করতে পারি।

#### ❓ প্রশ্ন ২.২: "বেইস থিওরেমের মেডিক্যাল ফলস-পজিটিভ প্যারাডক্স বাস্তব সংখ্যা দিয়ে ব্যাখ্যা করুন।"
**উত্তর:**
ধরি একটি বিরল রোগ জনসংখ্যায় ১% মানুষের আছে ($P(D) = 0.01$)।
একটি ল্যাব টেস্ট ৯৯% নিখুঁত:
- সংবেদনশীলতা (True Positive Rate): $P(+ \mid D) = 0.99$
- ফলস পজিটিভ রেট: $P(+ \mid \neg D) = 0.05$ (সুস্থ মানুষের ৫% পজিটিভ আসে)

**প্রশ্ন:** একজন ব্যক্তির টেস্ট পজিটিভ আসলে তার আসলেই রোগ থাকার সম্ভাবনা $P(D \mid +)$ কত?
$$\text{Bayes' Theorem}: \quad P(D \mid +) = \frac{P(+ \mid D) P(D)}{P(+ \mid D) P(D) + P(+ \mid \neg D) P(\neg D)}$$
$$P(D \mid +) = \frac{0.99 \times 0.01}{(0.99 \times 0.01) + (0.05 \times 0.99)} = \frac{0.0099}{0.0099 + 0.0495} = \frac{0.0099}{0.0594} \approx \mathbf{0.1667} \quad (\mathbf{16.7\%})!$$
- *অন্তর্দৃষ্টি:* টেস্ট ৯৯% নিখুঁত হওয়া সত্ত্বেও পজিটিভ রেজাল্ট আসার পর ওই ব্যক্তির রোগ থাকার সম্ভাবনা মাত্র ১৬.৭%! বাকি ৮৩.৩% ফলস অ্যালার্ম। এই কারণেই বেস রেট ফ্যালাসি (Base Rate Fallacy) এবং ইমব্যালান্সড ডেটায় প্রিসিশন-রিকল গুরুত্ব পায়।

#### ❓ প্রশ্ন ২.৩: "p-value কী, Type I বনাম Type II এরর কী, এবং বনফেরনি কারেকশন কেন প্রয়োজন?"
**উত্তর:**
- **p-value:** নাল হাইপোথিসিস ($H_0$) সত্যি ধরে নিলে প্রাপ্ত ফলাফলের সমান বা তার চেয়ে বেশি চরম ফলাফল পাওয়ার সম্ভাব্যতা। এটি নাল হাইপোথিসিস সত্যি হওয়ার সম্ভাবনা নয়!
- **Type I Error ($\alpha$):** False Positive (নির্দোষকে দোষী সাব্যস্ত করা বা ভুয়া সিগন্যালকে সত্য ভাবা)।
- **Type II Error ($\beta$):** False Negative (প্রকৃত রোগীকে সুস্থ বলে ছেড়ে দেওয়া)।
- **Bonferroni Correction:** যদি একসাথে $m$ টি হাইপোথিসিস টেস্ট করা হয়, তবে অন্তত একটিতে দৈবক্রমে $p < 0.05$ পাওয়ার সামগ্রিক সম্ভাবনা দাঁড়ায়: $1 - (1 - 0.05)^m$ ($m=20$ হলে সম্ভাবনা ৬৪%!)। বনফেরনি কারেকশন প্রতিটি টেস্টের সিগনিফিকেন্স থ্রেশহোল্ড সংকুচিত করে: $\alpha_{\text{new}} = \frac{\alpha}{m}$।

#### ❓ প্রশ্ন ২.৪: "Singular Value Decomposition (SVD) এর জ্যামিতিক তাৎপর্য কী?"
**উত্তর:**
যেকোনো বাস্তব ম্যাট্রিক্স $A \in \mathbb{R}^{m \times n}$-কে তিনটি জ্যামিতিক রূপান্তরের গুণফলে ভাঙা যায়:
$$A = U \Sigma V^\top$$
1. $V^\top$: ইনপুট স্পেসে রোটেশন (আইগেনভেক্টরসমূহ)।
2. $\Sigma$: প্রতিটি অক্ষ বরাবর স্কেলিং (সিঙ্গুলার ভ্যালু $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$)।
3. $U$: আউটপুট স্পেসে দ্বিতীয় রোটেশন।
- **লো-র‍্যাঙ্ক অ্যাপ্রক্সিমেশন (Eckart-Young-Mirsky Theorem):** শীর্ষ $k$ টি সিঙ্গুলার ভ্যালু রেখে বাকিগুলো শূন্য করে দিলে ফ্রবেনিয়াস নর্মে ম্যাট্রিক্সের সর্বোত্তম সংকোচন পাওয়া যায়, যা রিকমেন্ডার সিস্টেমে ইউজার-আইটেম ম্যাট্রিক্স কম্প্রেশনে ব্যবহৃত হয়।

### পিলার ৩: ক্লাসিক্যাল এমএল ও বুস্টিং

#### ❓ প্রশ্ন ৩.১: "Bias-Variance Trade-off-এর গাণিতিক ডিকম্পোজিশন প্রমাণ করুন।"
**উত্তর:**
ধরি প্রকৃত সম্পর্ক $y = f(x) + \epsilon$, যেখানে নয়েজ $\mathbb{E}[\epsilon] = 0$ এবং $\text{Var}(\epsilon) = \sigma^2$।
একটি প্রশিক্ষিত মডেল $\hat{f}(x)$-এর প্রত্যাশিত বর্গীয় ত্রুটি (Expected MSE):
$$\mathbb{E}[(y - \hat{f}(x))^2] = \text{Bias}[\hat{f}(x)]^2 + \text{Var}[\hat{f}(x)] + \sigma^2$$
1. **$\text{Bias}^2 = (\mathbb{E}[\hat{f}(x)] - f(x))^2$:** মডেলের ভুল ধারণাগত অনুমানের কারণে তৈরি ত্রুটি (আন্ডারফিটিং)।
2. **$\text{Variance} = \mathbb{E}[(\hat{f}(x) - \mathbb{E}[\hat{f}(x)])^2]$:** ট্রেইনিং ডেটার ক্ষুদ্র পরিবর্তনে মডেল প্রেডিকশনের অতিরিক্ত সংবেদনশীলতা (ওভারফিটিং)।
3. **$\sigma^2$ (Irreducible Error):** ডেটার অন্তর্নিহিত নয়েজ, যা কোনো অ্যালগরিদম দিয়েই কমানো সম্ভব নয়।

#### ❓ প্রশ্ন ৩.২: "কেন $L_1$ রেগুলারাইজেশন (Lasso) স্পার্সিটি তৈরি করে কিন্তু $L_2$ (Ridge) করে না?"
**উত্তর:**
- জ্যামিতিকভাবে, $L_2$ পেনাল্টি হলো একটি মসৃণ গোলক বা বৃত্ত ($w_1^2 + w_2^2 \le t$)। কনট্যুর লাইনের স্পর্শক সচরাচর অক্ষের মাঝে বৃত্তাকার তলে মিলিত হয়, ফলে ওয়েট ক্ষুদ্র হলেও অশূন্য থাকে।
- $L_1$ পেনাল্টি হলো একটি তীক্ষ্ণ ডায়মন্ড বা অষ্টভুজ ($|w_1| + |w_2| \le t$), যার কোণগুলো সরাসরি অক্ষের ওপর ($w_1 = 0$ বা $w_2 = 0$) অবস্থান করে। লস ফাংশনের উপবৃত্তাকার কনট্যুর সর্বদা এই তীক্ষ্ণ কোণে প্রথমে স্পর্শ করে, যার ফলে অনেক অপ্রয়োজনীয় ফিচারের ওয়েট হুবহু **শূন্য ($0.0$)** হয়ে যায় (স্বয়ংক্রিয় ফিচার সিলেকশন)।

#### ❓ প্রশ্ন ৩.৩: "XGBoost কীভাবে ২য় ক্রমের টেলর সিরিজ (Second-Order Taylor Expansion) ব্যবহার করে অপটিমাল স্প্লিট খুঁজে পায়?"
**উত্তর:**
ট্রি $t$-এর অবজেক্টিভ ফাংশন:
$$\mathcal{L}^{(t)} = \sum_{i=1}^n l(y_i, \hat{y}_i^{(t-1)} + f_t(x_i)) + \Omega(f_t)$$
টেলর সিরিজের ২য় ক্রমের বিস্তৃতি ($l(y, \hat{y} + \Delta) \approx l + g_i \Delta + \frac{1}{2} h_i \Delta^2$):
$$\tilde{\mathcal{L}}^{(t)} \approx \sum_{i=1}^n \left[ g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \gamma T + \frac{1}{2}\lambda \sum_{j=1}^T w_j^2$$
যেখানে $g_i = \partial_{\hat{y}} l$ (১ম ডেরিভেটিভ) এবং $h_i = \partial^2_{\hat{y}} l$ (হেসিয়ান বা ২য় ডেরিভেটিভ)।
- একটি লিফে অপটিমাল ওয়েট: $w_j^* = - \frac{G_j}{H_j + \lambda}$, যেখানে $G_j = \sum_{i \in I_j} g_i, H_j = \sum_{i \in I_j} h_i$।
- **স্প্লিট গেইন সমীকরণ (Split Gain Formula):**
  $$\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma$$
  এই সুনির্দিষ্ট গেইন সূত্রের কারণে XGBoost যেকোনো কাস্টম লস ফাংশন সমর্থন করতে পারে।

#### ❓ প্রশ্ন ৩.৪: "Random Forest-এ Out-of-Bag (OOB) এরর গাণিতিকভাবে কেন $\approx 36.8\%$ হয়?"
**উত্তর:**
$n$ আকারের একটি ডেটাসেট থেকে উইথ-রিপ্লেসমেন্ট (Bootstrap) স্যাম্পলিংয়ে একটি নির্দিষ্ট স্যাম্পল নির্বাচিত না হওয়ার সম্ভাবনা: $1 - \frac{1}{n}$।
$n$ বার স্বাধীনভাবে ড্র করলে স্যাম্পলটি কখনোই নির্বাচিত না হওয়ার সম্ভাবনা:
$$\lim_{n \to \infty} \left( 1 - \frac{1}{n} \right)^n = e^{-1} = \frac{1}{e} \approx \mathbf{0.3679} \quad (\mathbf{36.8\%})$$
অর্থাৎ প্রতিটি ট্রিতে গড়ে প্রায় ৩৬.৮% ডেটা অব্যবহৃত (OOB) থেকে যায়, যা পৃথক ভ্যালিডেশন সেট ছাড়াই মডেলের নিঃস্বার্থ টেস্ট এরর মাপতে ব্যবহৃত হয়।

### পিলার ৪: ডিপ লার্নিং ও ব্যাকপ্রোপাগেশন

#### ❓ প্রশ্ন ৪.১: "কেন Sigmoid অ্যাক্টিভেশনে ভ্যানিশিং গ্রেডিয়েন্ট হয়, এবং ReLU ও ResNet কীভাবে এটি সমাধান করে?"
**উত্তর:**
- সিগময়েডের ডেরিভেটিভ: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$। এর সর্বোচ্চ মান মাত্র **০.২৫** (যখন $z = 0$)।
- ব্যাকপ্রোপাগেশনের চেইন রুলে প্রতি লেয়ারে গ্রেডিয়েন্ট গুণ হতে হতে ১০টি লেয়ার পার হলে গ্রেডিয়েন্ট $(0.25)^{10} \approx 10^{-6}$ এ বিলীন হয়ে যায়।
- **ReLU:** পজিটিভ ইনপুটে ডেরিভেটিভ সর্বদা **১.০** ($\frac{d}{dz}\text{ReLU} = 1$), ফলে কোনো সংকোচন হয় না।
- **ResNet:** রেসিডুয়াল স্কিপ কানেকশন $a^{[l+1]} = \mathcal{F}(a^{[l]}) + a^{[l]}$ ব্যবহার করে। ডেরিভেটিভ নিলে আসে: $\frac{\partial a^{[l+1]}}{\partial a^{[l]}} = \frac{\partial \mathcal{F}}{\partial a^{[l]}} + \mathbf{1}$। এই অতিরিক্ত $+1$ একটি গ্রেডিয়েন্ট হাইওয়ে তৈরি করে সরাসরি পেছনের লেয়ারে সিগন্যাল পাঠায়, ফলে ১০০+ লেয়ারেও ভ্যানিশিং গ্রেডিয়েন্ট নির্মূল হয়।

#### ❓ প্রশ্ন ৪.২: "AdamW-তে কেন Decoupled Weight Decay প্রয়োজন হয়েছিল?"
**উত্তর:**
স্ট্যান্ডার্ড অ্যাডামে $L_2$ পেনাল্টি যোগ করলে গ্রেডিয়েন্ট হয়: $g_t' = g_t + \lambda w_t$।
কিন্তু অ্যাডামের হিস্টোরিক্যাল ভ্যারিয়্যান্স $v_t$ এই অতিরিক্ত $\lambda w_t$-কেও স্কেল ডাউন করে ফেলে! ফলে যে প্যারামিটারের গ্রেডিয়েন্ট বড়, তার ওয়েট ডিকে কম হয়।
**Loshchilov & Hutter (2019)** এর সমাধান: ওয়েট ডিকে সরাসরি ওয়েটের সাথে গুণ করা, গ্রেডিয়েন্টের সাথে নয়:
$$w_{t+1} = w_t (1 - \eta \lambda) - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$

#### ❓ প্রশ্ন ৪.৩: "ডিপ লার্নিংয়ে কেন BatchNorm টেস্ট টাইমে ট্রেইনিং টাইমের চেয়ে ভিন্ন আচরণ করে?"
**উত্তর:**
- **ট্রেইনিংয়ের সময়:** BatchNorm বর্তমান মিনি-ব্যাচের নিজস্ব গড় ($\mu_B$) এবং ভ্যারিয়্যান্স ($\sigma_B^2$) দিয়ে ডেটা নরমাল করে এবং একটি রানিং গড় ($\mu_{\text{run}}$) ও রানিং ভ্যারিয়্যান্স আপডেট করে।
- **টেস্ট / ইনফারেন্স টাইমে:** ব্যাচের সাইজ ১ হতে পারে (একক রিকোয়েস্ট); তাই টেস্ট টাইমে বর্তমান ব্যাচের গড় নেওয়া অর্থহীন। টেস্ট টাইমে পুরো ট্রেনিং জুড়ে সংগৃহীত স্থির **Exponential Moving Average ($\mu_{\text{run}}, \sigma_{\text{run}}^2$)** ব্যবহার করা হয়।

#### ❓ প্রশ্ন ৪.৪: "Transformer Scaled Dot-Product Attention-এ কেন $\sqrt{d_k}$ দিয়ে ভাগ করতে হয়?"
**উত্তর:**
ধরি কুয়েরি $q$ এবং কি $k$ ভেক্টরের উপাদানগুলো স্বাধীন ও তাদের গড় $0$ এবং ভ্যারিয়্যান্স $1$ ($\mathbb{E}[q_i] = 0, \text{Var}(q_i) = 1$)।
ডট প্রোডাক্ট $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ এর ভ্যারিয়্যান্স:
$$\text{Var}(q \cdot k) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} 1 = \mathbf{d_k}$$
যদি $d_k = 64$ বা $128$ হয়, তবে ডট প্রোডাক্টের ভ্যারিয়্যান্স অনেক বড় হয়ে যায়। এর ফলে সফটম্যাক্স ফাংশন চরম স্যাচুরেশনে চলে যায় এবং গ্রেডিয়েন্ট অত্যন্ত ক্ষুদ্র (ভ্যানিশিং) হয়ে যায়। $\sqrt{d_k}$ দিয়ে ভাগ করলে ভ্যারিয়্যান্স পুনরায় **১.০**-এ নেমে আসে: $\text{Var}\left(\frac{q \cdot k}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = \mathbf{1.0}$।

### পিলার ৫: প্রোডাকশন এমএলঅপ্স, ড্রিফট ও রোলব্যাক

#### ❓ প্রশ্ন ৫.১: "আপনার মডেলের অফলাইন টেস্ট স্কোর ৯৫% ছিল, কিন্তু প্রোডাকশন রিলিজের পর গ্রাহকরা অভিযোগ করছে। আপনি কীভাবে সমস্যাটি ইনভেস্টিগেট করবেন?"
**উত্তর (প্রফেশনাল কাঠামো):**
1. **ইনপুট স্কিমা ও নাল অডিট:** আপস্ট্রিম ফ্রন্টএন্ড কোনো নতুন ফিল্ড পাঠাচ্ছে কিনা বা `null` রেট বেড়েছে কিনা যাচাই করা।
2. **ড্রিফট পরীক্ষা (PSI):** প্রোডাকশনের ডেটা এবং ট্রেনিং ডেটার মধ্যে **Population Stability Index (PSI)** হিসাব করা। $\text{PSI} > 0.25$ হলে বুঝতে হবে কাস্টমার ডিস্ট্রিবিউশন শিফট হয়েছে।
3. **ট্রেনিং-সার্ভিং স্কিউ:** ফিচার তৈরির লজিকে কোনো অফলাইন বনাম অনলাইন পার্থক্য আছে কিনা অডিট করা।
4. **তাৎক্ষণিক প্রশমন:** যদি এরর রেট বেশি হয়, তবে ৬০ সেকেন্ডের মধ্যে কুবারনেটিস ট্রাফিক পূর্ববর্তী স্থিতিশীল মডেল সংস্করণে **অটো-রোলব্যাক** করা।

#### ❓ প্রশ্ন ৫.২: "Delayed Ground Truth সমস্যায় কীভাবে লেবেল ছাড়াই মডেলের অবনমন শনাক্ত করবেন?"
**উত্তর:**
ক্রেডিট কার্ড ফ্রড বা ঋণ খেলাপি মডেলে আসল সত্য ($y$) জানতে ৩০-৯০ দিন লেগে যায়। লেবেলের অপেক্ষায় বসে না থেকে **প্রক্সি মেট্রিক্স** ট্র্যাক করতে হয়:
1. **প্রেডিকশন ডিস্ট্রিবিউশন:** মডেলের দৈনিক পজিটিভ প্রেডিকশন রেট (Fraud Flag Rate) ট্র্যাক করা। এটি স্বাভাবিক ২% থেকে হঠাৎ ১০%-এ উঠলে বুঝতে হবে ডেটায় বিপর্যয় ঘটেছে।
2. **ফিচার ড্রাইভেন PSI:** গুরুত্বপূর্ণ টপ-১০ ফিচারের PSI প্রতিদিন অটোমেটিক ট্র্যাক করা।
3. **কনফিডেন্স স্কোর স্কিউ:** মডেলের প্রেডিকশন প্রোবাবিলিটির এনট্রপি বা অনিশ্চয়তা বেড়ে গেছে কিনা তা মনিটর করা।

### পিলার ৬: সিস্টেম ডিজাইন ও বিহেভিওরাল ইন্টারভিউ

#### ❓ প্রশ্ন ৬.১: "একটি ৪৫ মিনিটের এমএল সিস্টেম ডিজাইন ইন্টারভিউ পরিচালনার আর্কিটেকচারাল ফ্রেমওয়ার্ক কী?"
**উত্তর:**
1. **মিনিট ০–৫ (Clarify Scope & Metrics):** বিজনেস গোল, ইনপুট/আউটপুট, লেটেন্সি SLA ($P99 < 30\text{ms}$), এবং স্কেল (QPS, DAU)।
2. **মিনিট ৫–১০ (Back-of-the-Envelope):** স্টোরেজ, ট্রাফিক QPS, এবং জিপিইউ মেমরি সাইজিং।
3. **মিনিট ১০–২০ (High-Level Architecture):** ইনজেশন, স্টোরেজ, অফলাইন ট্রেইনিং, অনলাইন টু-স্টেজ সার্ভিং (Retrieval $\to$ Ranking)।
4. **মিনিট ২০–৩৫ (Deep Dive Components):** ফিচার স্টোর সিঙ্ক, মডেল সিলেকশন, ডাইনামিক ব্যাচিং ও ক্যাশিং।
5. **মিনিট ৩৫–৪৫ (Monitoring, Failure & Trade-offs):** ড্রিফট, ক্যানারি রিলিজ, ফলব্যাক হিউরিস্টিকস এবং সিস্টেমের সীমাবদ্ধতা।

# ৭. প্রোডাকশন-গ্রেড পাইথন ইমপ্লিমেন্টেশন কোড

### ৭.১ অটোমেটেড বিজনেস কস্ট অপটিমাইজেশন স্ক্রিপ্ট

```python
"""
cost_sensitive_threshold_optimizer.py
Optimizes decision threshold based on business cost matrix (False Negative vs False Positive)
"""
import numpy as np

def find_optimal_threshold(y_true: np.ndarray, y_probs: np.ndarray, cost_fn: float = 100.0, cost_fp: float = 20.0):
    """
    ব্যবসায়িক খরচের ভিত্তিতে অপটিমাল ডিসিশন থ্রেশহোল্ড বের করে।
    cost_fn: একজন ফ্রড গ্রাহক মিস করার ক্ষতি ($100)
    cost_fp: একজন নিরীহ গ্রাহককে অযথা ব্লক করার ক্ষতি ($20)
    """
    thresholds = np.linspace(0.01, 0.99, 100)
    best_threshold = 0.5
    min_cost = float('inf')
    cost_history = []

    for t in thresholds:
        y_pred = (y_probs >= t).astype(int)
        
        # ফলস নেগেটিভ ও ফলস পজিটিভ গণনা
        fn = np.sum((y_true == 1) & (y_pred == 0))
        fp = np.sum((y_true == 0) & (y_pred == 1))
        
        total_cost = (fn * cost_fn) + (fp * cost_fp)
        cost_history.append((t, total_cost, fn, fp))
        
        if total_cost < min_cost:
            min_cost = total_cost
            best_threshold = t

    return best_threshold, min_cost, cost_history

if __name__ == "__main__":
    np.random.seed(42)
    # ১০০০ জন গ্রাহক (১০% প্রকৃত ফ্রড)
    y_test = np.random.choice([0, 1], size=1000, p=[0.90, 0.10])
    # বাস্তবসম্মত নয়েজি স্কোর
    y_scores = np.clip(y_test * 0.35 + np.random.beta(2, 4, size=1000) * 0.55, 0, 1)

    opt_t, min_c, _ = find_optimal_threshold(y_test, y_scores, cost_fn=100.0, cost_fp=20.0)
    
    # ডিফল্ট ০.৫ থ্রেশহোল্ডের খরচ
    def_pred = (y_scores >= 0.5).astype(int)
    def_cost = (np.sum((y_test == 1) & (def_pred == 0)) * 100.0) + (np.sum((y_test == 0) & (def_pred == 1)) * 20.0)

    print(f"📊 ডিফল্ট থ্রেশহোল্ড (০.৫০) এ ব্যবসায়িক ক্ষতি: ${def_cost:,.2f}")
    print(f"🎯 অপটিমাইজড থ্রেশহোল্ড ({opt_t:.2f}) এ ব্যবসায়িক ক্ষতি: ${min_c:,.2f}")
    print(f"💰 নিট মাসিক সাশ্রয়: ${def_cost - min_c:,.2f} ({((def_cost - min_c)/def_cost)*100:.1f}%)")
```

### ৭.২ মডেল ফেয়ারনেস ও ডিসপারেট ইমপ্যাক্ট রেশিও (DIR) অডিটর

```python
"""
fairness_disparate_impact_auditor.py
Audits machine learning model for subpopulation bias using the 80% (Four-Fifths) Rule
"""
import numpy as np

def compute_disparate_impact(y_pred: np.ndarray, sensitive_attr: np.ndarray, unprivileged_val: int = 0, privileged_val: int = 1):
    """
    Disparate Impact Ratio (DIR) গণনা করে।
    DIR = P(Y_hat = 1 | Unprivileged) / P(Y_hat = 1 | Privileged)
    আইনগত মানদণ্ড: DIR >= 0.80 হলে বায়াসমুক্ত ধরা হয়।
    """
    unprivileged_mask = (sensitive_attr == unprivileged_val)
    privileged_mask = (sensitive_attr == privileged_val)

    p_unprivileged = np.mean(y_pred[unprivileged_mask])
    p_privileged = np.mean(y_pred[privileged_mask])

    dir_score = p_unprivileged / p_privileged if p_privileged > 0 else 0.0
    is_fair = bool((dir_score >= 0.80) and (dir_score <= 1.25))

    return {
        "p_unprivileged": round(float(p_unprivileged), 4),
        "p_privileged": round(float(p_privileged), 4),
        "disparate_impact_ratio": round(float(dir_score), 4),
        "is_fair_under_80_percent_rule": is_fair
    }

if __name__ == "__main__":
    np.random.seed(42)
    # ২০০০ জন আবেদনকারী (sensitive_attr: 0 = Rural, 1 = Urban)
    demographics = np.random.choice([0, 1], size=2000, p=[0.40, 0.60])
    
    # মডেলের প্রেডিকশন (১ = চুজেন / লোন অ্যাপ্রুভড)
    predictions = np.zeros(2000, dtype=int)
    predictions[demographics == 0] = np.random.choice([0, 1], size=np.sum(demographics == 0), p=[0.85, 0.15])
    predictions[demographics == 1] = np.random.choice([0, 1], size=np.sum(demographics == 1), p=[0.84, 0.16])

    audit = compute_disparate_impact(predictions, demographics, unprivileged_val=0, privileged_val=1)
    
    print("📋 মডেল ফেয়ারনেস ও বায়াস অডিট রিপোর্ট:")
    for k, v in audit.items():
        print(f"  • {k}: {v}")
    
    if audit["is_fair_under_80_percent_rule"]:
        print("✅ মডেলটি ৪/৫ (৮০%) নীতি অনুসারে আইনগতভাবে পক্ষপাতহীন!")
    else:
        print("⚠️ সতর্কবাণী: মডেলে বৈষম্যমূলক প্রভাব (Disparate Impact) পাওয়া গেছে!")
```
